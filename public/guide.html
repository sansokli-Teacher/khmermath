ណែនាំការប្រើប្រាស់សម្រាប់គ្រូ

ពីការត្រៀមតេស្ត រហូតដល់ថ្ងៃប្រឡង និងការប្រកាសលទ្ធផល។

ក្នុងមួយភ្លែត

  1. ថ្នាក់ និងសិស្ស — បង្កើតថ្នាក់ ហើយនាំចូលបញ្ជីសិស្ស (Excel)។ សិស្សចូលដោយអត្តលេខ (និងថ្ងៃកំណើត បើបើកជម្រើសនេះ)។
  2. តេស្ត — បន្ថែមសំណួរ ឬយកពីធនាគារសំណួរ។ សូមសរសេរ «ការពន្យល់ចម្លើយ» ដើម្បីឱ្យសិស្សរៀនពីកំហុស។
  3. កំណត់ពេលប្រឡង — ជ្រើសតេស្ត ថ្នាក់ ម៉ោង និង PIN។ ប្រព័ន្ធបង្ហាញ «បញ្ជីពិនិត្យ» មុនបង្កើត។
  4. ថ្ងៃប្រឡង — ប្រាប់ PIN ដល់សិស្ស ហើយមើលផ្ទាំង «ដាក់ពិន្ទុ និងលទ្ធផល» (ធ្វើបច្ចុប្បន្នភាពខ្លួនឯង)។
  5. ក្រោយប្រឡង — ដាក់ពិន្ទុផ្នែកសរសេរ មើលជាមុន ហើយផ្សព្វផ្សាយលទ្ធផល។

១. ត្រៀមសំណួរ

  • ការពន្យល់ចម្លើយ៖ សិស្សឃើញក្រោយលោកគ្រូប្រកាសលទ្ធផល និងក្នុងការហាត់សំណួរដែលធ្លាប់ខុស។
  • 🎲 លេខខុសគ្នាសម្រាប់សិស្សម្នាក់ៗ៖ បើសិស្សចម្លងគ្នា ឬផ្ញើរូបថតសំណួរ ចម្លើយរបស់មិត្តនឹងមិនត្រូវទេ ព្រោះលេខខុសគ្នា។ ឧទាហរណ៍៖
    អត្ថបទ[[a]] + [[b]] = ?
    ជម្រើស (ក ជាចម្លើយត្រូវ)[[a+b]] · [[a+b+1]] · [[a*b]] · [[a-b]]
    អថេរa = 2..9 និង b = 3..9 (ក៏អាច c = {2,4,5} ឬ d = a + b)
    ចុច «មើលឧទាហរណ៍» មុនរក្សាទុក។ ការបោះពុម្ពក្រដាស បង្ហាញលេខឧទាហរណ៍មួយឈុត។ ចម្លើយត្រូវបានកំណត់តាមទីតាំងជម្រើស ដូច្នេះត្រូវដាក់កន្សោមត្រឹមត្រូវនៅទីតាំងចម្លើយត្រូវ។
  • ប្រធានបទ (topic) ដែលបំពេញនឹងបង្ហាញក្នុងរបាយការណ៍ និងក្នុងផ្ទាំង «ការរីកចម្រើនរបស់ខ្ញុំ» របស់សិស្ស។

២. កំណត់ពេល និងការការពារ

  • 📋 បញ្ជីពិនិត្យ៖ រកឃើញជម្រើសខុស រូបភាពបាត់ ពិន្ទុ បញ្ជីសិស្ស ម៉ោង និង PIN។ កំហុស (✗) រារាំងការបង្កើត ការព្រមាន (⚠) សុំការបញ្ជាក់។
  • ការការពារភាពស្មោះត្រង់៖
    • 🔒 តឹងរ៉ឹង៖ បន្ទាប់ពីចាកចេញទំព័រ/ថតអេក្រង់ ជាដើម គ្រប់ N លើក សំណួរត្រូវលាក់ រហូតលោកគ្រូដោះសោ។
    • ⚠ ព្រមាន៖ លាក់សំណួរពេលចាកចេញ ព្រមាន និងកត់ត្រា។
    • 📝 កត់ត្រាតែប៉ុណ្ណោះ៖ មិនរំខានសិស្ស តែលោកគ្រូឃើញកំណត់ហេតុ។
  • ប្រព័ន្ធមិនអាចទប់ស្កាត់ប៊ូតុងថតអេក្រង់ ឬ AI របស់ទូរស័ព្ទខ្លួនឯងបានទេ — ប្រព័ន្ធលាក់សំណួរ កត់ត្រា និងដាក់សញ្ញាទឹក (ឈ្មោះសិស្ស) ប៉ុណ្ណោះ។ ការដើរមើលក្នុងថ្នាក់នៅតែសំខាន់បំផុត។

៣. ថ្ងៃប្រឡង

ស្ថានភាពអ្វីដែលត្រូវធ្វើ
សិស្សភ្លេច PIN / ចូលមិនបានប្រាប់ PIN ម្តងទៀត (បង្ហាញនៅក្នុងបញ្ជីការប្រឡង)។ ប្តូរ PIN បាន។
សិស្សបាត់អ៊ីនធឺណិតគ្មានអ្វីត្រូវធ្វើ — ចម្លើយរក្សាលើទូរស័ព្ទ ហើយផ្ញើវិញពេលមានអ៊ីនធឺណិត។ ក្រោយអស់ម៉ោង បើផ្ញើមិនបាន សូមចុច «+5'» ឱ្យសិស្សនោះ ហើយឱ្យគាត់បើកទំព័រវិញ។
សិស្សប្តូរទូរស័ព្ទចុចប៊ូតុង 📱 ក្បែរឈ្មោះសិស្ស រួចឱ្យគាត់បើកលើទូរស័ព្ទថ្មី។ ឧបករណ៍ចាស់នឹងត្រូវបិទ។
សិស្សជាប់សោ 🔒ចុចលើជួរ «សកម្មភាពគួរឱ្យសង្ស័យ» មើលកំណត់ហេតុ សួរសិស្ស រួចចុច «🔓 ដោះសោ» (សំណួរត្រឡប់មកក្នុង ១២ វិនាទី)។
សិស្សចុចប្រគល់ច្រឡំចុច «🔄 Reset» ក្នុងជួររបស់សិស្ស។
មានឧបករណ៍ទីពីរព្យាយាមចូលឃើញក្នុងកំណត់ហេតុថា «មានឧបករណ៍ផ្សេងព្យាយាមចូល» — ត្រូវបានបដិសេធរួចហើយ។ សួរសិស្សថាជាអ្នកណា។
ត្រូវការពេលបន្ថែម«⏱ បន្ថែមពេលថ្នាក់» ឬ «+5'» ក្បែរសិស្សម្នាក់។

សរសេរ កំណត់ចំណាំ ក្នុងកំណត់ហេតុរបស់សិស្ស ពេលឃើញអ្វីដោយផ្ទាល់ (ឧ. «មើលទូរស័ព្ទទីពីរ»)។ វាត្រូវបានរក្សាជាមួយលទ្ធផល។

៤. ក្រោយប្រឡង

  1. ដាក់ពិន្ទុសរសេរ៖ ប្រើ «✎ ដាក់ពិន្ទុសរសេរតាមសំណួរ» — ពិន្ទុសំណួរមួយ សិស្សទាំងថ្នាក់ ចុច Enter ទៅបន្ទាប់។
  2. ពិនិត្យ៖ «📊 ការវិភាគសំណួរ» ចង្អុលសំណួរដែលអាចមានចម្លើយខុស។ បើដូច្នេះ កែចម្លើយត្រឹមត្រូវ ហើយចុច «រាប់ពិន្ទុឡើងវិញ»។ 🔎 សូចនាករគួរឱ្យសង្ស័យជាសញ្ញាតែប៉ុណ្ណោះ មិនមែនភស្តុតាង។
  3. ផ្សព្វផ្សាយ៖ «👁 មើលជាមុន និងផ្សព្វផ្សាយ» បង្ហាញអ្វីដែលសិស្សនឹងឃើញ។ ដកចេញវិញបាន («↩ ដកលទ្ធផលចេញ»)។
  4. របាយការណ៍ថ្នាក់ 🖨៖ មួយទំព័រ — មធ្យម ការបែងចែកនិទ្ទេស សំណួរពិបាក ប្រធានបទខ្សោយ និងពិន្ទុសិស្សទាំងអស់។
  5. ប្រឡងម្តងទៀត៖ ក្នុងបញ្ជីការប្រឡង ចុច «↻ ប្រើម្តងទៀត» សម្រាប់ថ្នាក់ផ្សេង ឬប្រឡងជួសជុល។

៥. សម្រាប់សិស្ស

  • ផ្ទាំង «📚 ការរីកចម្រើនរបស់ខ្ញុំ» បង្ហាញពិន្ទុតាមការប្រឡង និងប្រធានបទដែលត្រូវរៀនបន្ថែម។
  • «🔁 ហាត់សំណួរដែលធ្លាប់ខុស» ឱ្យសិស្សហាត់ឡើងវិញជាមួយការពន្យល់ ហើយមិនបញ្ជូនពិន្ទុទៅលោកគ្រូទេ។
  • អាចដំឡើងជាកម្មវិធីលើអេក្រង់ដើមទូរស័ព្ទ។

៦. ការបម្រុងទុក (ម្ចាស់ប្រព័ន្ធ)

  • ប្រព័ន្ធបម្រុងទុកដោយស្វ័យប្រវត្តិរៀងរាល់ថ្ងៃចន្ទ ហើយពិនិត្យថាអាចអានបាន (ប្រាប់តាម Telegram បើមានបញ្ហា)។
  • ការកំណត់ → «♻ ស្ដារទិន្នន័យ» ផ្ទៀងផ្ទាត់ជាមុន ហើយស្ដារតែអ្វីដែលបាត់។ សូមធ្វើការផ្ទៀងផ្ទាត់មួយដងក្នុងមួយខែ។
