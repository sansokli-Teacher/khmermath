មុំ 60°។ A និង B នៅលើធ្នូរង្វង់ផ្ចិត O តែមួយ ដូច្នេះ OA = OB។ ធ្នូផ្ចិត A មានកាំដដែល ដូច្នេះ AB = OA។ ត្រីកោណ OAB មានជ្រុងទាំងបីប៉ុនគ្នា៖ វាជាត្រីកោណសម័ង្ស។ មុំទាំងបីរបស់វាប៉ុនគ្នា ហើយផលបូករង្វាស់មុំក្នុងទាំងបីនៃត្រីកោណស្មើនឹង 180° ដូច្នេះមុំនីមួយៗមានរង្វាស់ 180° ÷ 3 = 60°។

មុំ 30°។ OA = OB និង CA = CB ដូច្នេះ OC ជាកន្លះបន្ទាត់ពុះមុំ AOB។ មុំ xOz = 60° ÷ 2 = 30°។

មុំ 90°។ OP = OQ និង BP = BQ ដូច្នេះ O និង B នៅលើមេដ្យាទ័រនៃអង្កត់ PQ។ មេដ្យាទ័រកែងនឹងអង្កត់ ដូច្នេះ Oy កែងនឹង Ox។

មុំ 45°។ OQ = OR និង CQ = CR ដូច្នេះ OC ជាកន្លះបន្ទាត់ពុះមុំកែង xOy។ មុំ xOz = 90° ÷ 2 = 45°។

ពីមុំទាំងបួននេះ គេសង់មុំផ្សេងទៀតបាន៖ 120° = 60° + 60°, 15° = 30° ÷ 2, 75° = 60° + 15°, 135° = 90° + 45°។

កំហុសដែលច្រើនជួប

  • ប្ដូរគម្លាតដែកឈាន ពេលប្ដូរពី O ទៅ A (មុំ 60° និង 30°)។ ពេលនោះ AB មិនស្មើ OA ត្រីកោណ OAB មិនមែនជាត្រីកោណសម័ង្ស ហើយមុំមិនមែន 60° ទេ។ សាកល្បងដោយរំកិល «គម្លាតដែកឈាន» ខាងលើ។
  • គូសធ្នូផ្ចិត O ខ្លីពេក។ ធ្នូផ្ចិត A មិនកាត់វាទេ។ ត្រូវគូសធ្នូផ្ចិត O ឱ្យវែងឡើងទៅលើ។
  • មិនបន្លាយ Ox ឱ្យត្រង់ (មុំ 90° និង 45°)។ បើ P, O និង Q មិននៅលើបន្ទាត់តែមួយ នោះ OB មិនកែងនឹង Ox ទេ។ ត្រូវដាក់បន្ទាត់ឱ្យជាប់នឹង Ox មុននឹងបន្លាយ។
  • កាំតូចពេក (មុំ 90° និង 45°)។ បើកាំមិនធំជាង OP ធ្នូផ្ចិត P និង Q មិនកាត់គ្នាទេ។

សាកធ្វើលើក្រដាស

  1. គូសកន្លះបន្ទាត់ Ox មួយ។ សង់មុំ xOy = 60° ដោយប្រើដែកឈាន និងបន្ទាត់ រួចពិនិត្យដោយរ៉ាប័រទ័រ។
  2. សង់មុំ 30° មុំ 90° និងមុំ 45° រួចពិនិត្យមុំនីមួយៗដោយរ៉ាប័រទ័រ។
  3. សង់ត្រីកោណសម័ង្ស ABC ដែលមានជ្រុង 5 cm។
    មើលចម្លើយ

    គូសអង្កត់ AB = 5 cm។ បើកដែកឈាន 5 cm រួចគូសធ្នូរង្វង់ផ្ចិត A និងធ្នូរង្វង់ផ្ចិត B។ ធ្នូទាំងពីរកាត់គ្នាត្រង់ចំណុច C។ គូសអង្កត់ AC និង BC។

  4. សង់មុំ 120° ដោយប្រើតែដែកឈាន និងបន្ទាត់។
    មើលចម្លើយ

    គូសធ្នូរង្វង់ផ្ចិត O ឱ្យកាត់ Ox ត្រង់ A។ រក្សាគម្លាតដែកឈាន៖ ពី A ដៅចំណុច B លើធ្នូ រួចពី B ដៅចំណុច C លើធ្នូដដែល។ មុំ AOC = 60° + 60° = 120°។

  5. តើគេសង់មុំ 15° និងមុំ 75° ដូចម្ដេច?
    មើលចម្លើយ

    ពុះមុំ 30° ជាពីរ បានមុំ 15°។ សង់មុំ 60° និងមុំ 90° លើកន្លះបន្ទាត់ Ox តែមួយ រួចពុះមុំដែលនៅចន្លោះកន្លះបន្ទាត់ទាំងពីរ (30°) ជាពីរ៖ បានមុំ 60° + 15° = 75°។
