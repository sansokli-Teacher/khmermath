សាកល្បងខ្លួនឯង

អូសកំពូល A, B ឬ C ដើម្បីប្ដូររូបត្រីកោណ ឬជ្រើសរើសករណីមួយខាងក្រោម។ សង្កេតមើលថាផ្ចិត O នៅត្រង់ណា៖ ក្នុងត្រីកោណ លើជ្រុង ឬក្រៅត្រីកោណ។

  1. គេឱ្យត្រីកោណ ABC។ យើងចង់សង់រង្វង់ដែលកាត់តាមកំពូលទាំងបី A, B និង C៖ រង្វង់ចារឹកក្រៅត្រីកោណ។
  2. សង់មេដ្យាទ័រនៃជ្រុង AB៖ គូសធ្នូរង្វង់ផ្ចិត A រួចផ្ចិត B ដោយកាំដូចគ្នា (ធំជាង ½AB) ឱ្យកាត់គ្នាត្រង់ពីរចំណុច។
  3. ប្រើបន្ទាត់ គូសបន្ទាត់កាត់តាមចំណុចទាំងពីរនោះ។ វាជាមេដ្យាទ័រនៃជ្រុង AB។
  4. ធ្វើដូចគ្នាចំពោះជ្រុង BC៖ គូសធ្នូរង្វង់ផ្ចិត B រួចផ្ចិត C ដោយកាំដូចគ្នា (ធំជាង ½BC) ឱ្យកាត់គ្នាត្រង់ពីរចំណុច។
  5. ប្រើបន្ទាត់ គូសមេដ្យាទ័រនៃជ្រុង BC។ មេដ្យាទ័រទាំងពីរប្រសព្វគ្នាត្រង់ចំណុច O។
  6. ដៅចុងម្ជុលដែកឈាននៅ O បើកដែកឈានដល់ A រួចគូសរង្វង់ផ្ចិត O កាំ OA។
  7. រង្វង់នេះកាត់តាម A, B និង C ព្រោះ OA = OB = OC។ O ជាផ្ចិតរង្វង់ចារឹកក្រៅត្រីកោណ ABC។

សាកល្បងខ្លួនឯង

អូសកំពូល A, B ឬ C ដើម្បីប្ដូររូបត្រីកោណ។ ផ្ចិត I នៅក្នុងត្រីកោណជានិច្ច ហើយរង្វង់នៅតែប៉ះជ្រុងទាំងបី។

  1. គេឱ្យត្រីកោណ ABC។ យើងចង់សង់រង្វង់នៅក្នុងត្រីកោណ ដែលប៉ះនឹងជ្រុងទាំងបី៖ រង្វង់ចារឹកក្នុងត្រីកោណ។
  2. សង់កន្លះបន្ទាត់ពុះមុំ A៖ គូសធ្នូរង្វង់ផ្ចិត A ឱ្យកាត់ជ្រុងទាំងពីរនៃមុំ រួចពីចំណុចទាំងពីរនោះ គូសធ្នូពីរដោយកាំដូចគ្នា ឱ្យកាត់គ្នា។
  3. ប្រើបន្ទាត់ គូសកន្លះបន្ទាត់ពីកំពូល A កាត់តាមចំណុចប្រសព្វនៃធ្នូទាំងពីរ។ វាជាកន្លះបន្ទាត់ពុះមុំ A។
  4. ធ្វើដូចគ្នាចំពោះមុំ B៖ គូសធ្នូរង្វង់ផ្ចិត B ឱ្យកាត់ជ្រុងទាំងពីរនៃមុំ រួចគូសធ្នូពីរដោយកាំដូចគ្នា ឱ្យកាត់គ្នា។
  5. ប្រើបន្ទាត់ គូសកន្លះបន្ទាត់ពុះមុំ B។ កន្លះបន្ទាត់ពុះទាំងពីរប្រសព្វគ្នាត្រង់ចំណុច I។
  6. រកចម្ងាយពី I ទៅជ្រុង AB៖ គូសធ្នូរង្វង់ផ្ចិត I ឱ្យកាត់ AB ត្រង់ពីរចំណុច រួចពីចំណុចទាំងពីរនោះ គូសធ្នូពីរដោយកាំដូចគ្នា ឱ្យកាត់គ្នានៅម្ខាងទៀតនៃ AB។
  7. ប្រើបន្ទាត់ គូសបន្ទាត់ពី I ទៅចំណុចប្រសព្វនោះ។ វាកែងនឹង AB ត្រង់ចំណុច D។
  8. ដៅចុងម្ជុលដែកឈាននៅ I បើកដែកឈានដល់ D រួចគូសរង្វង់ផ្ចិត I កាំ ID។
  9. រង្វង់នេះប៉ះជ្រុងទាំងបីត្រង់ D, E និង F ព្រោះ ID = IE = IF។ I ជាផ្ចិតរង្វង់ចារឹកក្នុងត្រីកោណ ABC។

ហេតុអ្វីបានជាត្រឹមត្រូវ?

រង្វង់ចារឹកក្រៅ។ គ្រប់ចំណុចឋិតនៅលើមេដ្យាទ័រនៃអង្កត់មួយ ត្រូវឋិតនៅស្មើចម្ងាយពីចុងទាំងពីរនៃអង្កត់នោះ។ O នៅលើមេដ្យាទ័រនៃ AB ដូច្នេះ OA = OB ហើយនៅលើមេដ្យាទ័រនៃ BC ដូច្នេះ OB = OC។ គេបាន OA = OB = OC៖ រង្វង់ផ្ចិត O កាំ OA កាត់តាមកំពូលទាំងបី។

រង្វង់ចារឹកក្នុង។ គ្រប់ចំណុចនៅលើកន្លះបន្ទាត់ពុះនៃមុំមួយ ត្រូវឋិតនៅស្មើចម្ងាយពីជ្រុងទាំងពីរនៃមុំនោះ។ I នៅលើកន្លះបន្ទាត់ពុះមុំ A និងមុំ B ដូច្នេះ ID = IF និង ID = IE។ រង្វង់ផ្ចិត I កាំ ID ប៉ះជ្រុងនីមួយៗត្រង់ជើងនៃអង្កត់កែង ព្រោះបន្ទាត់ប៉ះនៃរង្វង់កែងនឹងកាំត្រង់ចំណុចប៉ះ។

មេដ្យាទ័រជ្រុងទាំងបីនៃត្រីកោណមួយប្រសព្វគ្នាត្រង់ចំណុចតែមួយ ហើយកន្លះបន្ទាត់ពុះមុំក្នុងទាំងបីក៏ប្រសព្វគ្នាត្រង់ចំណុចតែមួយដែរ។ ដូច្នេះសង់តែពីរគ្រប់គ្រាន់៖ ទីបី (បន្ទាត់ដាច់ៗក្នុងជំហានចុងក្រោយ) កាត់តាមចំណុចដដែល។

  • ច្រឡំបន្ទាត់។ មេដ្យាទ័រ ឱ្យផ្ចិតរង្វង់ចារឹកក្រៅ។ កន្លះបន្ទាត់ពុះមុំ ឱ្យផ្ចិតរង្វង់ចារឹកក្នុង។ មេដ្យាន និងកម្ពស់ មិនឱ្យផ្ចិតរង្វង់ណាមួយទេ។
  • បើកដែកឈានពី I ទៅជ្រុងដោយភ្នែក។ កាំនៃរង្វង់ចារឹកក្នុងជាចម្ងាយពី I ទៅជ្រុង ដែលត្រូវវាស់តាមអង្កត់កែង ID។ បើកាំធំពេក រង្វង់កាត់ជ្រុង។ បើតូចពេក វាមិនប៉ះជ្រុងទេ។
  • ចង់ឱ្យ O នៅក្នុងត្រីកោណជានិច្ច។ បើត្រីកោណមានមុំទាលមួយ O នៅក្រៅត្រីកោណ។ បើជាត្រីកោណកែង O ជាចំណុចកណ្ដាលនៃអ៊ីប៉ូតេនុស។ សាកល្បងជ្រើសរើសករណីខាងលើ។
  • កាំនៃធ្នូតូចពេក ពេលសង់មេដ្យាទ័រ។ បើកាំមិនធំជាងពាក់កណ្ដាលជ្រុង ធ្នូទាំងពីរមិនកាត់គ្នាទេ។

សាកធ្វើលើក្រដាស

  1. សង់ត្រីកោណ ABC ដែល AB = 6 cm, AC = 5 cm និង BC = 4 cm។ សង់រង្វង់ចារឹកក្រៅ និងរង្វង់ចារឹកក្នុងរបស់វា។
  2. គូសត្រីកោណកែងមួយ រួចសង់រង្វង់ចារឹកក្រៅរបស់វា។ តើផ្ចិត O នៅត្រង់ណា?
    មើលចម្លើយ

    O ជាចំណុចកណ្ដាលនៃអ៊ីប៉ូតេនុស ហើយអ៊ីប៉ូតេនុសជាអង្កត់ផ្ចិតនៃរង្វង់។

  3. សង់ត្រីកោណសម័ង្សដែលមានជ្រុង 6 cm រួចសង់រង្វង់ទាំងពីរ។ តើអ្នកសង្កេតឃើញអ្វី?
    មើលចម្លើយ

    រង្វង់ទាំងពីរមានផ្ចិតតែមួយ ហើយកាំនៃរង្វង់ចារឹកក្រៅស្មើនឹងពីរដងនៃកាំរង្វង់ចារឹកក្នុង។

  4. គេមានចំណុចបី A, B និង C មិនរត់ត្រង់ជួរគ្នា។ សង់រង្វង់ដែលកាត់តាមចំណុចទាំងបី។
    មើលចម្លើយ

    សង់មេដ្យាទ័រនៃ AB និងនៃ BC។ ចំណុចប្រសព្វ O ជាផ្ចិត ហើយ OA ជាកាំ។ មានរង្វង់តែមួយគត់ដែលកាត់តាមចំណុចទាំងបី។
