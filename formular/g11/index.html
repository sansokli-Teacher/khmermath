( ក្រៅពីតួទី 1 ) ស្មើនឹងតួមុនបន្ទាប់បូកចំនួនថេរ \(\displaystyle d\) មួយ
( ហៅថាផលសងរួម \(\displaystyle d = U_{n+1} - U_n\) ) ។

( ក្រៅពីតួទី 1 ) ស្មើនឹងតួមុនបន្ទាប់គុណនឹងចំនួនថេរ \(\displaystyle q\) ដែល \(\displaystyle q \neq 0\) ។ ចំនួនថេរ \(\displaystyle q\) នេះហៅថាផលធៀបរួមស្វុីតធរណីមាត្រ ។

☞  ព្រឹត្តិការណ៍ផលគុណនៃ \(\displaystyle A\) និង \(\displaystyle B\) ជាប្រសព្វនៃព្រឹត្តិការណ៍ \(\displaystyle A\) និងព្រឹត្តិការណ៍ \(\displaystyle B\) ។ គេកំណត់សរសេរ \(\displaystyle A\) និង \(\displaystyle B\) មានន័យថា \(\displaystyle A \cap B\) ។
☞  ព្រឹត្តិការណ៍ផលបូកនៃ \(\displaystyle A\) និង \(\displaystyle B\) ជាប្រជុំនៃព្រឹត្តិការណ៍ \(\displaystyle A\) និងព្រឹត្តិការណ៍ \(\displaystyle B\) ។ គេកំណត់សរសេរ \(\displaystyle A\) ឬ \(\displaystyle B\) មានន័យថា \(\displaystyle A \cup B\) ។

គន្លឹះដោះស្រាយមេរៀនប្រូបាប
  1. លំហសំណាក (\(\displaystyle S\)): រកចំនួនលទ្ធផលសរុបដែលអាចកើតឡើង ។ \(\displaystyle n(S) = \text{ករណីអាច}\)
  2. កំណត់ព្រឹត្តិការណ៍ (\(\displaystyle A\)): រកចំនួនករណីតាមបំណងប្រាថ្នា ។ \(\displaystyle n(A) = \text{ករណីស្រប}\)
  3. ប្រើរូបមន្ត: ប្រូបាបនៃព្រឹត្តិការណ៍ \(\displaystyle A\) គឺ៖ \(\displaystyle P(A) = \frac{n(A)}{n(S)}\) ចំណាំ៖ \(\displaystyle 0 \leq P(A) \leq 1\)

  4. ពាក្យគន្លឹះដែលត្រូវចាំ:

    • ពាក្យថា "ឬ" (\(\displaystyle A \cup B\)): ប្រើការបូក \(\displaystyle P(A) + P(B) - P(A \cap B)\)

ចំនួនកុំផ្លិច

មេរៀន ចំនួនកុំផ្លិចទម្រង់ពីជគណិត

កុំផ្លិចឆ្លាស់ និងកុំផ្លិចផ្ទុយ
  • បើគេមានចំនួនកុំផ្លិច\(\displaystyle ~z=a+bi~\)នោះចំនួនកុំផ្លិចឆ្លាស់\(\displaystyle ~z~\)តាងដោយ \(\displaystyle \overline{z}=a-bi\) ។
  • ចំនួនកុំផ្លិចផ្ទុយនៃចំនួនកុំផ្លិច\(\displaystyle ~z=a+bi~\)តាងដោយ \(\displaystyle -z=-a-bi\) ។
ប្រមាណវិធីលើកុំផ្លិច
  • វិធីបូកចំនួនកុំផ្លិច
    \(\displaystyle ~(a+bi)+(c+di)=(a+c)+(b+d)i~\)
  • វិធីដកចំនួនកុំផ្លិច
    \(\displaystyle ~(a+bi)-(c+di)=(a-c)+(b-d)i~\)
  • វិធីគុណចំនួនកុំផ្លិច
    \(\displaystyle ~(a+bi)(c+di)=(ac-bd)+(ad+bc)i~\)

  • វិធីចែកចំនួនកុំផ្លិច

    \[\begin{aligned}~\dfrac{(a+bi)}{(c+di)}&=\dfrac{(a+bi)(c-di)}{(c+di)(c-di)}&\\ &=\dfrac{ac+bd}{c^2+d^2}+\dfrac{bc-ad}{c^2+d^2}~។ \end{aligned}\]

    ចំពោះ\(\displaystyle ~c+di\neq0~\)

លក្ខណៈនៃចំនួនកុំផ្លិចឆ្លាស់
  • កុំផ្លិចឆ្លាស់នៃបូកដកកុំផ្លិចពីរ
    គេបាន\(\displaystyle ~\overline{z_1\pm z_2}=\overline{z_1}\pm \overline{z_2}~\)។
  • កុំផ្លិចឆ្លាស់នៃផលគុណកុំផ្លិចពីរ
    គេបាន\(\displaystyle ~\overline{z_1\cdot z_2}=\overline{z_1}\cdot \overline{z_2}~\)។
  • កុំផ្លិចឆ្លាស់នៃផលចែកកុំផ្លិចពីរ
    គេបាន\(\displaystyle ~\overline {\left(\dfrac{z_1}{z_2}\right)}=\dfrac{\overline {z_1}}{\overline{z_2}}~\)។

មេរៀន ចំនួនកុំផ្លិចទម្រង់ត្រីកោណមាត្រ

ម៉ូឌុលនៃចំនួនកុំផ្លិច

គេមានចំនួនកុំផ្លិច\(\displaystyle ~z=a+bi~\)គេតាងម៉ូឌុលនៃ\(\displaystyle ~z~\)ដោយ\(\displaystyle ~|z|~\)កំណត់សរសេរដោយ
\(\displaystyle ~r=|z|=\sqrt{a^2+b^2}~\)។

ការេនៃម៉ូឌុលគឺជាផលគុណរវាងចំនួនកុំផ្លិច\(\displaystyle ~z~\)និងកុំផ្លិចឆ្លាស់របស់វា

បើ\(\displaystyle ~z~\)ជាចំនួនកុំផ្លិច នោះ\(\displaystyle ~|z|^2=z\cdot \overline{z}~\)។

ម៉ូឌុលនៃចំនួនកុំផ្លិច

បើ\(\displaystyle ~z~\)ជាចំនួនកុំផ្លិច នោះ\(\displaystyle ~|z|=|\overline{z}|=|-z|~\)។

ម៉ូឌុលនៃផលគុណស្មើនឹងផលគុណនៃម៉ូឌុល

បើ\(\displaystyle ~z~\)ជាចំនួនកុំផ្លិច នោះ\(\displaystyle ~|z_1\cdot z_2|=|z_1|\cdot |z_2|~\)។

ម៉ូឌុលនៃផលចែកស្មើនឹងផលចែកនៃម៉ូឌុល

បើ\(\displaystyle ~z~\)ជាចំនួនកុំផ្លិច នោះ\(\displaystyle ~\left|\dfrac{z_1}{z_2}\right|=\dfrac{|z_1|}{|z_2|}~\)។

គន្លិះដោះស្រាយ

 \(\displaystyle r=\sqrt{a^2+b^2}\) និង \(\displaystyle \varphi\) ជាអាគុយម៉ង់នៃ\(\displaystyle ~z~\)។

ទម្រង់ត្រីកោណមាត្រនៃចំនួនកុំផ្លិច

ផលគុណកុំផ្លិចក្នុងទម្រង់ត្រីកោណមាត្រ
