# Team game: fair turns, no class re-pick, absent students, result picture (2026-10-22)
- **Class not asked again** (teach-app): the class card the teacher opens is remembered (`teach_active_class`). The wizard starts at «មេរៀន» when the class is known (it used to start at the class list even when the class was given); the home «លេងហ្គេម» button uses the remembered class (a «ប្តូរថ្នាក់» button remains). The game's «Teaching» link returns to the same class (`teach/?back=game`).
- **Absent students**: the wizard reads today's attendance (latest period that has marks, mark A) and adds it to the Spin's crossed-out names; they are not put in groups and are listed in the wizard and counted on the result picture.
- **Fair card count**: teams open cards in turn, so questions + bonus boxes must divide by the number of teams. `planCards()` (public/js/teamgame.js, teach-app/src/fair.js): 1) add missing questions from the lessons' spare questions, 2) else add bonus boxes (max 12), 3) else remove the surplus (questions first, the bonus stays). The wizard and the game page show «ក្រុមនីមួយៗបើក N កាត», and the game applies the same rule when it starts. Default group count is 6.
- **Result**: class name, teacher name, date and time on the result card and in the picture; new button «📋 ចម្លងរូបភាព» (copies the PNG to the clipboard; falls back to the PNG download if the browser refuses).
- Tested locally: 6 groups, 20 questions + 3 bonus -> 24 cards, each group opened 4 (simulated clicks). Not tested: a real clipboard paste on the teacher's computer, phone remote.
