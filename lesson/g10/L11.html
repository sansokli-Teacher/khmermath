មេរៀនទី 2: សមីការបន្ទាត់

ក្នុងមេរៀននេះ
  1. 1. ទម្រង់នៃសមីការបន្ទាត់
  2. 2. ទីតាំងធៀបរវាងបន្ទាត់ពីរ
  3. 3. ចម្ងាយរវាងចំណុចនិងបន្ទាត់

មេរៀនទាំងអស់
✓វត្ថុបំណង
  1. សរសេរសមីការបន្ទាត់តាមទម្រង់ផ្សេងៗ (កាត់តាមចំណុចមួយនិងស្គាល់មេគុណប្រាប់ទិស ឬកាត់តាមពីរចំណុច)
  2. កំណត់លក្ខខណ្ឌស្របគ្នា និងកែងគ្នានៃបន្ទាត់ពីរ
  3. គណនាចម្ងាយពីចំណុចមួយទៅបន្ទាត់មួយ និងមុំរវាងបន្ទាត់ពីរ ។

1. ទម្រង់នៃសមីការបន្ទាត់

  • ទម្រង់ចំណុចនិងមេគុណប្រាប់ទិស ៖ សមីការបន្ទាត់កាត់តាមចំណុច \(\displaystyle A(x_1, y_1)\) និងមានមេគុណប្រាប់ទិស \(\displaystyle m\) គឺ ៖

    \[y - y_1 = m(x - x_1)\]

  • ទម្រង់កាត់តាមពីរចំណុច ៖ បន្ទាត់កាត់តាម \(\displaystyle A(x_1, y_1)\) និង \(\displaystyle B(x_2, y_2)\) (\(\displaystyle x_1 \neq x_2\)) ៖

    \[y - y_1 = \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)\]
  • ទម្រង់ទូទៅ ៖ \(\displaystyle ax + by + c = 0\) (\(\displaystyle a^2 + b^2 \neq 0\)) ដែលមានមេគុណប្រាប់ទិស \(\displaystyle m = -\dfrac{a}{b}\) (បើ \(\displaystyle b \neq 0\)) ។
  • ទម្រង់សមីការចំណោត ៖ \(\displaystyle y = mx + b\) (\(\displaystyle m\) ជាមេគុណប្រាប់ទិស, \(\displaystyle b\) ជាអរដោនេគល់) ។

2. ទីតាំងធៀបរវាងបន្ទាត់ពីរ

គេឱ្យបន្ទាត់ពីរ \(\displaystyle L_1 : y = m_1 x + b_1\) និង \(\displaystyle L_2 : y = m_2 x + b_2\) ៖

  • បន្ទាត់ស្របគ្នា (\(\displaystyle L_1 \parallel L_2\)) ៖ លុះត្រាតែ \(\displaystyle m_1 = m_2\) និង \(\displaystyle b_1 \neq b_2\) ។
  • បន្ទាត់កែងគ្នា (\(\displaystyle L_1 \perp L_2\)) ៖ លុះត្រាតែ \(\displaystyle m_1 \cdot m_2 = -1\) ។

  • មុំ \(\displaystyle \theta\) រវាងបន្ទាត់ទាំងពីរ ៖

    \[\tan \theta = \left| \frac{m_2 - m_1}{1 + m_1 m_2} \right| \quad (m_1 m_2 \neq -1)\]

3. ចម្ងាយរវាងចំណុចនិងបន្ទាត់

ក. ចម្ងាយពីចំណុច \(\displaystyle P(x_0, y_0)\) ទៅបន្ទាត់ \(\displaystyle D : ax + by + c = 0\) ៖

\[d(P, D) = \frac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}\]

ខ. ចម្ងាយរវាងបន្ទាត់ស្របគ្នាពីរ \(\displaystyle ax + by + c_1 = 0\) និង \(\displaystyle ax + by + c_2 = 0\) ៖

\[d = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}\]

លំហាត់និងដំណោះស្រាយ

  1. រកសមីការបន្ទាត់កាត់តាមចំណុច \(\displaystyle A(2, -3)\) និងមានមេគុណប្រាប់ទិស \(\displaystyle m = 4\) ៖
    ដំណោះស្រាយ ៖

    \[y - y_1 = m(x - x_1) \iff y - (-3) = 4(x - 2) \iff y + 3 = 4x - 8 \iff y = 4x - 11 \text{ ឬ } 4x - y - 11 = 0 \text{ ។}\]
  2. រកសមីការបន្ទាត់ \(\displaystyle L\) កាត់តាមពីរចំណុច \(\displaystyle A(1, 2)\) និង \(\displaystyle B(3, 8)\) ៖
    ដំណោះស្រាយ ៖ មេគុណប្រាប់ទិស \(\displaystyle m = \frac{8 - 2}{3 - 1} = \frac{6}{2} = 3\) ។
    សមីការបន្ទាត់ ៖ \(\displaystyle y - 2 = 3(x - 1) \implies y = 3x - 1\) ឬ \(\displaystyle 3x - y - 1 = 0\) ។

  3. រកសមីការបន្ទាត់កាត់តាមចំណុច \(\displaystyle P(-1, 4)\) ហើយ ៖

    1. ក. ស្របនឹងបន្ទាត់ \(\displaystyle d_1 : y = 2x - 5\)
    2. ខ. កែងនឹងបន្ទាត់ \(\displaystyle d_2 : 3x - y + 1 = 0\)

    ដំណោះស្រាយ ៖

    • ក. បន្ទាត់ស្របនឹង \(\displaystyle d_1\) មានមេគុណប្រាប់ទិស \(\displaystyle m = 2\) ៖
      \(\displaystyle y - 4 = 2(x - (-1)) \iff y = 2x + 6\) ។
    • ខ. \(\displaystyle d_2\) មានមេគុណប្រាប់ទិស \(\displaystyle m_2 = 3\) នាំឱ្យមេគុណប្រាប់ទិសបន្ទាត់កែងគឺ \(\displaystyle m = -\frac{1}{3}\) ៖
      \(\displaystyle y - 4 = -\frac{1}{3}(x + 1) \iff 3y - 12 = -x - 1 \iff x + 3y - 11 = 0\) ។

  4. គណនាចម្ងាយពីចំណុច \(\displaystyle A(2, 3)\) ទៅបន្ទាត់ \(\displaystyle 3x + 4y - 8 = 0\) ៖
    ដំណោះស្រាយ ៖

    \[d = \frac{|3(2) + 4(3) - 8|}{\sqrt{3^2 + 4^2}} = \frac{|6 + 12 - 8|}{\sqrt{25}} = \frac{10}{5} = 2 \text{ ឯកតាប្រវែង ។}\]

  5. គណនាចម្ងាយរវាងបន្ទាត់ស្របគ្នាពីរ \(\displaystyle 3x - 4y + 5 = 0\) និង \(\displaystyle 3x - 4y - 15 = 0\) ៖
    ដំណោះស្រាយ ៖

    \[d = \frac{|5 - (-15)|}{\sqrt{3^2 + (-4)^2}} = \frac{|20|}{\sqrt{25}} = \frac{20}{5} = 4 \text{ ឯកតាប្រវែង ។}\]
