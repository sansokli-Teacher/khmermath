ដំណោះស្រាយ :

    គណនាផ្ទៃក្រឡាចម្ការជាអនុគមន៍នៃ \(\displaystyle x\)

    ដោយចម្ការនេះមានរាងជាចតុកោណកែងគេបានផ្ទៃក្រឡាចម្ការគឺ \(\displaystyle xy\) ដោយបរិមាត្រចម្ការស្មើនឹង \(\displaystyle 400\text{ m}\) នាំឱ្យ \(\displaystyle 2x + 2y = 400\) សមមូល \(\displaystyle x + y = 200 \implies y = 200 - x\) នោះគេបាន \(\displaystyle xy = x(200 - x) = 200x - x^2\) ដូច្នេះ ផ្ទៃក្រឡាចម្ការជាអនុគមន៍នៃ \(\displaystyle x\) គឺ \(\displaystyle A(x) = 200x - x^2\) ។

  2. ខ.

    គេមាន \(\displaystyle A(x) = 200x - x^2\) នោះគេបាន \(\displaystyle A'(x) = (200x - x^2)' = 200 - 2x\) ឱ្យ \(\displaystyle A'(x) = 0\) សមមូល \(\displaystyle 200 - 2x = 0 \iff x = 100\) ។

  2. ខ. កំណត់តម្លៃ \(\displaystyle x\) ដើម្បីឱ្យប្រអប់មានមាឌអតិបរមា រួចគណនាមាឌអតិបរមានោះ ។
