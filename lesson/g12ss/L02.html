2. ភាពជាប់ត្រង់មួយចំណុច

ឧទាហរណ៍ : គេមានអនុគមន៍

\[y = f(x) = \begin{cases} x^2 + 7 & \text{បើ } x \ge 0 \\ x + 7 & \text{បើ } x < 0 \end{cases}\]

គេបាន \(\displaystyle f(0) = 0^2 + 7 = 7\)

  • \(\displaystyle \lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} (x^2 + 7) = 0^2 + 7 = 7\)
  • \(\displaystyle \lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} (x + 7) = 0 + 7 = 7\)

ដោយ \(\displaystyle \lim_{x \to 0^+} f(x) = \lim_{x \to 0^-} f(x) = 7 = f(0)\) ដូច្នេះ \(\displaystyle \lim_{x \to 0} f(x) = 7 = f(0)\) ។ គេថា \(\displaystyle f\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle x = 0\) ។

និយមន័យ : អនុគមន៍ \(\displaystyle y = f(x)\) ជាប់ត្រង់ចំណុច \(\displaystyle x = c\) កាលណា \(\displaystyle f\) បំពេញលក្ខខណ្ឌទាំងបីដូចខាងក្រោម ៖

  1. \(\displaystyle f\) កំណត់ចំពោះ \(\displaystyle x = c\)
  2. \(\displaystyle f\) មានលីមីតកាលណា \(\displaystyle x \to c\)
  3. \(\displaystyle \lim_{x \to c} f(x) = f(c)\) ។

សម្គាល់ : បើអនុគមន៍ \(\displaystyle y = f(x)\) មិនជាប់ត្រង់ចំណុច \(\displaystyle x = c\) គេថា \(\displaystyle f\) ជាអនុគមន៍ដាច់ត្រង់ \(\displaystyle x = c\) ។

  2. ខ. អនុគមន៍ \(\displaystyle g\) កំណត់ដោយ \(\displaystyle g(x) = \begin{cases} -1 & \text{បើ } x < 0 \\ 1 & \text{បើ } x > 0 \end{cases}\) ។ តើ \(\displaystyle g\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle x = 0\) ឬទេ ?

    ត្រង់ \(\displaystyle x = 2\) នាំឱ្យ \(\displaystyle f(2) = 2^2 - 4 = 0\) ហើយ \(\displaystyle \lim_{x \to 2} f(x) = \lim_{x \to 2} (x^2 - 4) = 0\) គេបាន \(\displaystyle \lim_{x \to 2} f(x) = f(2) = 0\) ។ ដូច្នេះ អនុគមន៍ \(\displaystyle f\) ជាប់ត្រង់ \(\displaystyle x = 2\) ។

  2. ខ.

លំហាត់គំរូ 2 : គេមានអនុគមន៍ \(\displaystyle f(x) = \begin{cases} \dfrac{x^2 - 4}{x - 2} & \text{បើ } x \neq 2 \\ 4 & \text{បើ } x = 2 \end{cases}\) ។ បង្ហាញថា \(\displaystyle f\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle x = 2\) ។

ដំណោះស្រាយ : \(\displaystyle f\) កំណត់ត្រង់ \(\displaystyle x = 2\) ហើយ \(\displaystyle f(2) = 4\) ។ \(\displaystyle \lim_{x \to 2} f(x) = \lim_{x \to 2} \dfrac{x^2 - 4}{x - 2} = \lim_{x \to 2} (x + 2) = 4 = f(2)\) ដូច្នេះ \(\displaystyle f\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle 2\) ។

3. លក្ខណៈនៃអនុគមន៍ជាប់

ផ្អែកតាមលក្ខណៈនៃលីមីតនិងនិយមន័យភាពជាប់ គេបានលក្ខណៈនៃអនុគមន៍ជាប់ដូចខាងក្រោម ៖

បើអនុគមន៍ \(\displaystyle f\) និង \(\displaystyle g\) ជាប់ត្រង់ \(\displaystyle x = c\) នោះ គេបាន

  1. \(\displaystyle f(x) + g(x)\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle x = c\)
  2. \(\displaystyle f(x) - g(x)\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle x = c\)
  3. \(\displaystyle f(x) \cdot g(x)\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle x = c\)
  4. \(\displaystyle kf(x)\) ជាអនុគមន៍ជាប់ត្រង់ \(\displaystyle x = c\) (ដែល \(\displaystyle k\) ជាចំនួនថេរ)
  5. \(\displaystyle \dfrac{f(x)}{g(x)}\) ជាប់ត្រង់ \(\displaystyle x = c\) ដែល \(\displaystyle g(c) \neq 0\) ។
