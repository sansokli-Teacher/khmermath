ដំណោះស្រាយ ៖ រូបទី 1 ៖ បន្លាយជ្រុង \(\displaystyle Ox'\) កាត់ \(\displaystyle Oy\) ត្រង់ \(\displaystyle A\)[cite: 49] គេបាន \(\displaystyle \angle xOy = \angle x'Ay\) មុំត្រូវគ្នា[cite: 49] \(\displaystyle \angle x'O'y' = \angle x'Ay\) មុំត្រូវគ្នា[cite: 49] ដូច្នេះ \(\displaystyle \angle xOy = \angle x'O'y'\)[cite: 49]

រូបទី 2 ៖ ភ្ជាប់ \(\displaystyle OO'\) គេបាន[cite: 49] \(\displaystyle \angle O'Oy = \angle OO'x'\) មុំឆ្លាស់ក្នុង[cite: 49] \(\displaystyle \angle O'Ox = \angle OO'y'\) មុំឆ្លាស់ក្នុង នោះ[cite: 49] \(\displaystyle \angle O'Oy - \angle O'Ox = \angle OO'x' - \angle OO'y'\)[cite: 49] ដូច្នេះ \(\displaystyle \angle xOy = \angle x'O'y'\)[cite: 49]

រូបទី 3 ៖ បន្លាយជ្រុង \(\displaystyle Ox\) កាត់ \(\displaystyle O'y'\) ត្រង់ \(\displaystyle A\)[cite: 49] គេបាន \(\displaystyle \angle xOy = \angle xAO'\) មុំត្រូវគ្នា[cite: 49] \(\displaystyle \angle x'O'y' + \angle xAO' = 180^\circ\) ផលបូកមុំក្នុងរួមខាង[cite: 49] ដូច្នេះ \(\displaystyle \angle xOy + \angle x'O'y' = 180^\circ\) ។[cite: 49]

ជាទូទៅ[cite: 49] មុំពីរដែលមានជ្រុងត្រូវគ្នាស្របរៀងគ្នាគឺ[cite: 49] 1. ជាមុំប៉ុនគ្នា កាលណាវាស្រួចទាំងពីរ ឬទាលទាំងពីរ ។[cite: 49] 2. ជាមុំបន្ថែមគ្នា កាលណាមុំមួយស្រួច មួយទាល ។[cite: 49]

9. មុំមានជ្រុងត្រូវគ្នា កែងរៀងគ្នា

បើ \(\displaystyle Ox \perp O'x'\) និង \(\displaystyle Oy \perp O'y'\) នោះមុំ \(\displaystyle \angle xOy\) និង \(\displaystyle \angle x'O'y'\) ហៅថា មុំមានជ្រុងត្រូវគ្នាកែងរៀងគ្នា ។[cite: 49]

ឧទាហរណ៍ ៖ ក្នុងករណីនីមួយៗនៃរូបខាងលើបង្ហាញថា \(\displaystyle \angle xOy = \angle x'O'y'\) ឬ \(\displaystyle \angle xOy + \angle x'O'y' = 180^\circ\) ។[cite: 49]

រូបទី 1 ៖ តាម \(\displaystyle O\) គូស \(\displaystyle Ot \parallel O'y'\) រួច \(\displaystyle O'y'\) កាត់ \(\displaystyle Ox\) ត្រង់ចំណុច \(\displaystyle A\)[cite: 49] គេបាន \(\displaystyle \angle yOt = \angle O'Ay\) មុំត្រូវគ្នា[cite: 49] ហើយ \(\displaystyle \angle xOy = 90^\circ - \angle yOt, \angle x'O'y' = 90^\circ - \angle O'Ay\)[cite: 49] ដូច្នេះ \(\displaystyle \angle xOy = \angle x'O'y'\) ។[cite: 49]

រូបទី 2 ៖ តាម \(\displaystyle O\) គូស \(\displaystyle Ot \parallel O'y'\) នោះគេបាន \(\displaystyle Ot \perp O'y'\) រួច \(\displaystyle Ot\) កាត់ \(\displaystyle Ox\) ត្រង់ចំណុច \(\displaystyle A\)[cite: 49] គេបាន \(\displaystyle \angle OAx' = \angle x'O'y'\) មុំត្រូវគ្នា[cite: 49] ហើយ \(\displaystyle \angle xOy = 90^\circ - \angle xOA, \angle x'O'y' = 90^\circ - \angle xOA\)[cite: 49] ដូច្នេះ \(\displaystyle \angle xOy = \angle x'O'y'\) ។[cite: 49]

រូបទី 3 ៖ បន្លាយ \(\displaystyle Ox\) និង \(\displaystyle O'y'\) កាត់គ្នាត្រង់ \(\displaystyle A\)[cite: 49] គេបាន \(\displaystyle \angle AOy = \angle x'O'y'\) មុំមានជ្រុងត្រូវគ្នាកែងរៀងគ្នា[cite: 49] \(\displaystyle \angle AOy + \angle xOy = 180^\circ\) (មុំជាប់បន្ថែម)[cite: 49] ដូច្នេះ \(\displaystyle \angle xOy + \angle x'O'y' = 180^\circ\) ។[cite: 49]

ជាទូទៅ[cite: 49] មុំពីរមានជ្រុងត្រូវគ្នា កែងរៀងគ្នា គឺ[cite: 49] 1. ជាមុំប៉ុនគ្នា កាលណាមុំស្រួចទាំងពីរ ឬទាលទាំងពីរ ។[cite: 49] 2. ជាមុំបន្ថែមគ្នា កាលណាមុំមួយស្រួច មួយទាល ។[cite: 49]

លំហាត់គំរូ ៖ គេមានត្រីកោណ \(\displaystyle ABC\) ដែលមុំទាំងបីជាមុំស្រួច ហើយ \(\displaystyle H\) ជាអរតូសង់ ។ បង្ហាញថា \(\displaystyle \angle BAC + \angle BHC = 180^\circ\) ។[cite: 49]

ដំណោះស្រាយ ៖ គេមាន \(\displaystyle AB \perp CH, AC \perp BH\)[cite: 49] នោះមុំ \(\displaystyle \angle BAC\) និង \(\displaystyle \angle BHC\) មុំមានជ្រុងត្រូវគ្នាកែងរៀងគ្នា ។[cite: 49] ដោយមុំ \(\displaystyle \angle BAC\) ជាមុំស្រួចហើយ \(\displaystyle \angle BHC\) ជាមុំទាល ។[cite: 49] ដូច្នេះ \(\displaystyle \angle BAC + \angle BHC = 180^\circ\) ។[cite: 49]

ប្រតិបត្តិ ៖ គេមានត្រីកោណ \(\displaystyle ABC\) ដែលមុំ \(\displaystyle B\) ជាមុំទាល ហើយ \(\displaystyle H\) ជាអរតូសង់ ។ ប្រៀបធៀបមុំ \(\displaystyle \angle BAC\) និង \(\displaystyle \angle BHC\) ។[cite: 49] ចម្លើយ ៖ \(\displaystyle \angle BAC = \angle BHC\) មុំមានជ្រុងត្រូវគ្នាកែងរៀងគ្នា ។[cite: 49]
