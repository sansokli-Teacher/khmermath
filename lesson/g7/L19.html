1. ភាពឆ្លុះធៀបនឹងចំណុច

1.1. ភាពឆ្លុះធៀបនឹងចំណុច

គេមានចំណុចនឹង \(\displaystyle O\) មួយនិងចំណុច \(\displaystyle M\) មួយនៅក្នុងប្លង់ ។ គេគូសអង្កត់ \(\displaystyle MO\) រួចបន្លាយខាង \(\displaystyle O\) ឱ្យបាន \(\displaystyle OM' = OM\) ។ គេបាន \(\displaystyle O\) ជាចំណុចកណ្តាលនៃ \(\displaystyle MM'\) ហើយគេថាចំណុច \(\displaystyle M'\) ឆ្លុះនឹង \(\displaystyle M\) ធៀបនឹងចំណុច \(\displaystyle O\) ។ ចំណុច \(\displaystyle O\) ហៅថា ផ្ចិតឆ្លុះ ។ ចំណុចឆ្លុះនៃចំណុច \(\displaystyle O\) គឺចំណុច \(\displaystyle O\) ខ្លួនឯង ។

ជាទូទៅ ចំណុច \(\displaystyle M\) ឆ្លុះ \(\displaystyle M'\) ធៀបនឹងចំណុច \(\displaystyle O\) មួយកាលណា \(\displaystyle O\) ជាចំណុចកណ្តាលនៃអង្កត់ \(\displaystyle MM'\) ។

▶ មើលរូបមានចលនា៖ ចំណុចឆ្លុះធៀបនឹងចំណុច

1.2. ការសង់ចំណុច \(\displaystyle M'\) ជាចំណុចឆ្លុះនៃ \(\displaystyle M\) ធៀបនឹង \(\displaystyle O\)

1.2.1. ការប្រើប្រាស់បន្ទាត់

គេគូសកន្លះបន្ទាត់ \(\displaystyle MO\) រួចគេដៅចំណុច \(\displaystyle M'\) ដោយឱ្យ \(\displaystyle OM' = MO\) ។

▶ មើលរូបមានចលនា៖ សង់ M′ ដោយបន្ទាត់ក្រិត

1.2.2. ការប្រើដែកឈាននិងបន្ទាត់

គេគូសកន្លះបន្ទាត់ \(\displaystyle MO\) និងកន្លះរង្វង់ផ្ចិត \(\displaystyle O\) កាំ \(\displaystyle OM\) ។ កន្លះរង្វង់នេះកាត់កន្លះបន្ទាត់ \(\displaystyle MO\) ត្រង់ \(\displaystyle M'\) ។

▶ មើលរូបមានចលនា៖ សង់ M′ ដោយដែកឈាន

2. រូបឆ្លុះគ្នាធៀបនឹងចំណុច

គេថា \(\displaystyle A'\) ជារូបឆ្លុះនៃរូប \(\displaystyle A\) ធៀបនឹងចំណុច \(\displaystyle O\) ឬថារូប \(\displaystyle A\) និង \(\displaystyle A'\) ឆ្លុះគ្នាធៀបចំណុច \(\displaystyle O\) ។

▶ មើលរូបមានចលនា៖ រូបឆ្លុះគ្នាធៀបនឹងចំណុច

2.1. បន្ទាត់ឆ្លុះគ្នាធៀបនឹងចំណុច

រូបឆ្លុះនៃបន្ទាត់ \(\displaystyle d\) ធៀបចំណុច \(\displaystyle O\) (\(\displaystyle O \notin d\)) គឺបន្ទាត់ \(\displaystyle d'\) ស្របបន្ទាត់ \(\displaystyle d\) ។

បើចំណុច \(\displaystyle O\) ឋិតនៅលើបន្ទាត់ \(\displaystyle d\) នោះបន្ទាត់ \(\displaystyle d'\) ត្រួតស៊ីលើបន្ទាត់ \(\displaystyle d\) ។

▶ មើលរូបមានចលនា៖ រូបឆ្លុះធៀបនឹងចំណុច

បើចំណុច \(\displaystyle A, B\) និង \(\displaystyle C\) រត់ត្រង់ជួរ នោះចំណុចឆ្លុះវា \(\displaystyle A', B'\) និង \(\displaystyle C'\) ក៏រត់ត្រង់ជួរដែរ ។

2.2. អង្កត់ឆ្លុះគ្នាធៀបនឹងចំណុច

គេមានចំណុច \(\displaystyle A', B', I'\) ជាចំណុចឆ្លុះនៃចំណុច \(\displaystyle A, B, I\) ធៀបចំណុច \(\displaystyle O\) ។ បើអង្កត់ \(\displaystyle A'B'\) ឆ្លុះអង្កត់ \(\displaystyle AB\) ធៀបចំណុច \(\displaystyle O\) នោះ ៖

\[A'B' \parallel AB \quad \text{និង} \quad A'B' = AB\]

បើ \(\displaystyle I\) ជាចំណុចកណ្តាលនៃអង្កត់ \(\displaystyle AB\) នោះ \(\displaystyle I'\) ជាចំណុចកណ្តាលនៃអង្កត់ \(\displaystyle A'B'\) ។

▶ មើលរូបមានចលនា៖ អង្កត់ឆ្លុះគ្នាធៀបនឹងចំណុច

2.3. មុំឆ្លុះគ្នាធៀបនឹងចំណុច

រូបឆ្លុះនៃមុំមួយធៀបនឹងចំណុចមួយ ជារូបមួយទៀតដែលមានមុំប៉ុនគ្នា ៖

\[\angle x'A'y' = \angle xAy\]

រូបឆ្លុះនៃមុំកែងមួយធៀបនឹងចំណុចមួយ ជារូបមួយទៀតដែលមានមុំកែងដូចគ្នា ។

▶ មើលរូបមានចលនា៖ មុំឆ្លុះគ្នាធៀបនឹងចំណុច

ជាទូទៅ

  1. រូបពីរឆ្លុះគ្នាធៀបនឹងចំណុចមួយជារូបប៉ុនគ្នា ។
  2. បន្ទាត់ពីរឆ្លុះគ្នាធៀបនឹងចំណុចមួយជាបន្ទាត់ស្របគ្នា (បើបន្ទាត់មិនកាត់តាមផ្ចិតឆ្លុះ) ។
  3. អង្កត់ពីរឆ្លុះគ្នាធៀបនឹងចំណុចមួយជាអង្កត់ស្របគ្នានិងប៉ុនគ្នា ។
  4. មុំពីរឆ្លុះគ្នាធៀបនឹងចំណុចមួយជាមុំប៉ុនគ្នា ។

▶ មើលរូបមានចលនា៖ សង់រូបឆ្លុះធៀបនឹងចំណុច

5. អ័ក្សឆ្លុះនៃរូបធរណីមាត្រប្លង់
