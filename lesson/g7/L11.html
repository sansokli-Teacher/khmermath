ឧទាហរណ៍ 1 ៖ គេប្រៀបធៀបកម្ពស់សត្វឆ្កែនិងសត្វខ្លា ។
ការប្រៀបធៀបបរិមាណទាំងពីរនេះ \(\displaystyle 2~\text{cm}\) លើ \(\displaystyle 3~\text{cm}\) អាចសរសេរជាទម្រង់ \(\displaystyle 2 : 3\) អានថា «ពីរលើបី» ។
ផលធៀបនេះគេអាចសរសេរជាប្រភាគ \(\displaystyle \frac{2}{3}\) ។ ដូច្នេះគេអាចប្រៀបធៀបបរិមាណពីរដែលមានឯកតាដូចគ្នា ។

ជាទូទៅ

ផលធៀបនៃ \(\displaystyle a\) និង \(\displaystyle b\) ដែល \(\displaystyle a\) និង \(\displaystyle b\) ជាចំនួនគត់ (\(\displaystyle b \neq 0\)) ហើយតាងបរិមាណពីរដែលមានឯកតាដូចគ្នា គេអាចសរសេរជាទម្រង់ \(\displaystyle a : b\) ឬ \(\displaystyle \frac{a}{b}\) ។

លំហាត់គំរូ ៖ នៅក្នុងថ្នាក់ទី 7 «ក» មានសិស្ស 45 នាក់ ក្នុងនោះមានសិស្សស្រី 15 នាក់ ។ រកផលធៀបសិស្សប្រុសនិងសិស្សស្រី ។

ដំណោះស្រាយ
ចំនួនសិស្សប្រុសនៅក្នុងថ្នាក់ទី 7 «ក» មាន \(\displaystyle 45\text{ នាក់} - 15\text{ នាក់} = 30\text{ នាក់}\) ។
ផលធៀបសិស្សប្រុសនិងសិស្សស្រីគឺ \(\displaystyle 30 : 15\) ឬ \(\displaystyle \frac{30}{15} = \frac{2}{1}\) ។

ប្រតិបត្តិ 1 ៖ រកផលធៀប ក. \(\displaystyle 50~\text{g}\) និង \(\displaystyle 200~\text{g}\)   ខ. \(\displaystyle 700~\text{g}\) និង \(\displaystyle 1~\text{kg}\) ។

ចម្លើយ
ក. \(\displaystyle \frac{50}{200} = \frac{1}{4}\)   ខ. \(\displaystyle 1~\text{kg} = 1~000~\text{g} \implies \frac{700}{1~000} = \frac{7}{10}\) ។

ប្រតិបត្តិ 2 ៖ លោកប៊ុនណារកប្រាក់បាន \(\displaystyle \$1~200\) ហើយបានចំណាយអស់ \(\displaystyle \$450\) ក្នុងមួយខែ ។ រកផលធៀប ៖
ក. ប្រាក់ចំណូលរបស់គាត់និងប្រាក់ចំណាយរបស់គាត់
ខ. ប្រាក់សន្សំរបស់គាត់និងប្រាក់ចំណូលរបស់គាត់ ។

ចម្លើយ
ក. \(\displaystyle \frac{1200}{450} = \frac{8}{3}\)
ខ. ប្រាក់សន្សំគឺ \(\displaystyle 1~200 - 450 = 750\) ដុល្លារ នោះផលធៀបគឺ \(\displaystyle \frac{750}{1200} = \frac{5}{8}\) ។

2. ផលធៀបស្មើគ្នា

ឧទាហរណ៍ 2 ៖ បុរសបីនាក់ \(\displaystyle A, B\) និង \(\displaystyle C\) បានចែកប្រាក់ចំណេញគ្នាក្នុងការរកស៊ីចូលហ៊ុនគ្នាមួយ ។ ពួកគេបានទទួលប្រាក់ \(\displaystyle \$4~000, \$3~000\) និង \(\displaystyle \$1~000\) រៀងគ្នា ។

ដូចនេះពងទា 30 គ្រាប់ថ្លៃ \(\displaystyle = 700~\text{៛} \times 30 = 21~000~\text{៛}\) ។
ខ. ក្នុង \(\displaystyle 1~\text{km}\) ស៊ីសាំងអស់ \(\displaystyle = \frac{60~\ell}{570~\text{km}}\)

ដូចនេះបើរថយន្តធ្វើដំណើរ \(\displaystyle 190~\text{km}\) ស៊ីសាំងអស់ \(\displaystyle = \frac{2}{19} \times 190 = 20~\ell\) ។

ប្រភាគនីមួយៗនេះខុសគ្នាពីផលធៀបដោយវាទាក់ទងនឹងបរិមាណពីរប្រភេទដែលមានឯកតាខុសគ្នា ។ ប្រភាគនីមួយៗនេះហៅថា អត្រា « / » ។

3.2. ល្បឿនមធ្យម

ឧទាហរណ៍ ៖ ចាន់ដារ៉ានិងណារ៉ុងបានជិះកង់ប្រណាំងគ្នាលើចម្ងាយផ្លូវ \(\displaystyle 90~\text{km}\) ប្រើអស់ពេល 5 ម៉ោង និង \(\displaystyle 4\frac{1}{2}\) ម៉ោងរៀងគ្នា ។ តើអ្នកណាធ្វើដំណើរលឿនជាង?
ណារ៉ុងបានធ្វើដំណើរលឿនជាង ព្រោះគាត់ប្រើពេលអស់តិចជាង ដើម្បីបញ្ចប់ការប្រណាំងនេះ ។ គេក៏អាចបង្ហាញអត្រា ឬល្បឿនរបស់អ្នកទាំងពីរ ៖
ចាន់ដារ៉ា ៖ អត្រា ឬល្បឿនមធ្យម \(\displaystyle = \frac{90~\text{km}}{5~\text{h}} = 18~\text{km/h}\) ។
ណារ៉ុង ៖ អត្រា ឬល្បឿនមធ្យម \(\displaystyle = \frac{90~\text{km}}{4\frac{1}{2}~\text{h}} = 20~\text{km/h}\) ។
ដូចនេះ ណារ៉ុងធ្វើដំណើរបានលឿនជាង ព្រោះគាត់ធ្វើដំណើរដោយល្បឿនធំជាង និងប្រើរយៈពេលតិចជាង ។

ជាទូទៅ
\[\text{ល្បឿនមធ្យម} = \frac{\text{ចម្ងាយចរ}\rule[-0.5em]{0pt}{1.55em}}{\text{រយៈពេលចរ}\rule[-0.5em]{0pt}{1.55em}} \quad \text{ឬ} \quad v = \frac{d}{t}\]

ដែល \(\displaystyle v\) ជាល្បឿនមធ្យម, \(\displaystyle d\) ជាចម្ងាយចរ និង \(\displaystyle t\) ជារយៈពេលចរ ។

លំហាត់គំរូ 1 ៖ អ្នកជិះកង់ម្នាក់កំពុងធ្វើដំណើរដោយល្បឿនមធ្យម \(\displaystyle 18~\text{km/h}\) ។
ក. សរសេរល្បឿនមធ្យមរបស់គាត់គិតជា \(\displaystyle \text{m/s}\) ។
ខ. រកចម្ងាយចរដែលគាត់ធ្វើដំណើរក្នុងរយៈពេល 3 ម៉ោង ។

ដំណោះស្រាយ
ក. \(\displaystyle 18~\text{km} = 18 \times 1~000~\text{m} = 18~000~\text{m}\), \(\displaystyle 1~\text{h} = 60 \times 60 = 3~600~\text{s}\)
ដូចនេះ \(\displaystyle 18~\text{km/h} = \frac{18 \times 1~000~\text{m}}{3~600~\text{s}} = 5~\text{m/s}\) ។
ខ. ក្នុងរយៈពេល \(\displaystyle 3~\text{h}\) អ្នកជិះកង់ធ្វើដំណើរបាន \(\displaystyle 18 \times 3 = 54~\text{km}\) ។

ជាទូទៅ
\[\text{ចម្ងាយចរ} = \text{ល្បឿនមធ្យម} \times \text{រយៈពេលចរ} \quad \text{ឬ} \quad d = v \times t\]

លំហាត់គំរូ 2 ៖ រថភ្លើងមួយធ្វើដំណើរដោយល្បឿនមធ្យម \(\displaystyle 15~\text{m/s}\) ។
ក. រករយៈពេលដែលរថភ្លើងចរក្នុងចម្ងាយផ្លូវ \(\displaystyle 750~\text{m}\) ។
ខ. បើរថភ្លើងនេះចេញដំណើរពីស្ថានីយ A នៅម៉ោង 8 ព្រឹក ។ តើរថភ្លើងនេះទៅដល់ស្ថានីយ B នៅម៉ោងប៉ុន្មាន? បើពី A ទៅ B មានចម្ងាយផ្លូវកាត់គ្នា \(\displaystyle 36~\text{km}\) ។

ដំណោះស្រាយ
ក. \(\displaystyle d = 750~\text{m}, v = 15~\text{m/s} \implies t = \frac{d}{v} = \frac{750}{15} = 50~\text{s}\)
ដូចនេះ រយៈពេលចរស្មើនឹង \(\displaystyle 50~\text{s}\) ។
ខ. \(\displaystyle d = 36~\text{km} = 36~000~\text{m}\)
\(\displaystyle t = \frac{d}{v} = \frac{36~000}{15} = 2~400~\text{s} = \frac{2~400}{60} = 40~\text{mn}\)
ដូចនេះ រថភ្លើងនេះទៅដល់ស្ថានីយ B នៅម៉ោង \(\displaystyle 8~\text{h}~40~\text{mn}\) ព្រឹក ។

✎ប្រតិបត្តិ


បើរថយន្តមួយធ្វើដំណើរក្នុងចម្ងាយផ្លូវ \(\displaystyle 91~\text{km}\) វាស៊ីសាំងអស់ \(\displaystyle 7~\ell\) ។
ក. តើរថយន្តនេះធ្វើដំណើរបានចម្ងាយប៉ុន្មាន \(\displaystyle \text{km}\) បើមានសាំង \(\displaystyle 15~\ell\)?
ខ. តើម្ចាស់រថយន្តនេះបានចំណាយប្រាក់លើថ្លៃសាំងអស់ប៉ុន្មានរៀលនៅពេលគាត់ធ្វើដំណើរបានចម្ងាយ \(\displaystyle 260~\text{km}\) ដោយសាំង \(\displaystyle 1~\ell\) ថ្លៃ \(\displaystyle 4~000~\text{៛}\)?

មើលចម្លើយ


ក. អត្រាស៊ីសាំងគឺ \(\displaystyle \frac{91}{7} = 13~\text{km}/\ell\) នោះចម្ងាយចរគឺ \(\displaystyle 15 \times 13 = 195~\text{km}\) ។
ខ. សាំងដែលត្រូវប្រើសម្រាប់ \(\displaystyle 260~\text{km}\) គឺ \(\displaystyle \frac{260}{13} = 20~\ell\) ។
ប្រាក់ត្រូវចំណាយគឺ \(\displaystyle 20 \times 4~000 = 80~000~\text{៛}\) ។

4. សមាមាត្រ

4.1. សមាមាត្រស្រប

ឧទាហរណ៍ ៖ អង្ករនៅក្នុងថង់នីមួយៗមានម៉ាសខុសៗគ្នា និងត្រូវលក់ក្នុងតម្លៃខុសៗគ្នា ។

គេធ្វើផលធៀបម៉ាសនិងផលធៀបតម្លៃរបស់វារៀងគ្នាដូចខាងក្រោម ៖

ផលធៀបម៉ាសផលធៀបតម្លៃ
\(\displaystyle 3~\text{kg} : 6~\text{kg} = 1 : 2\)\(\displaystyle 4~800~\text{៛} : 9~600~\text{៛} = 1 : 2\)
\(\displaystyle 3~\text{kg} : 9~\text{kg} = 1 : 3\)\(\displaystyle 4~800~\text{៛} : 14~400~\text{៛} = 1 : 3\)
\(\displaystyle 6~\text{kg} : 9~\text{kg} = 2 : 3\)\(\displaystyle 9~600~\text{៛} : 14~400~\text{៛} = 2 : 3\)

គេកត់សម្គាល់ឃើញថា ផលធៀបម៉ាសនិងផលធៀបតម្លៃរបស់វាស្មើគ្នា ។
គេនិយាយថាតម្លៃសមាមាត្រទៅនឹងម៉ាស ឬតម្លៃជាសមាមាត្រស្របទៅនឹងម៉ាស ។
គេសម្គាល់ឃើញថា គូផលធៀបតម្លៃនិងម៉ាសរៀងគ្នា \(\displaystyle \frac{3}{6}\) និង \(\displaystyle \frac{4~800}{9~600}\), \(\displaystyle \frac{3}{9}\) និង \(\displaystyle \frac{4~800}{14~400}\), \(\displaystyle \frac{6}{9}\) និង \(\displaystyle \frac{9~600}{14~400}\) ជាផលធៀបសមមូលគ្នា ។
ដូច្នេះ \(\displaystyle \frac{3}{6}\) និង \(\displaystyle \frac{4~800}{9~600}\), \(\displaystyle \dots\) គឺជាសមាមាត្រ ហើយចំនួន 3 និង 6, 4 800 និង 9 600, \(\displaystyle \dots\) ហៅថា គូនៃសមាមាត្រ ។
កាលណាបរិមាណពីរគូមានផលធៀបស្មើគ្នា បរិមាណទាំងនេះជាគូនៃសមាមាត្រ ។
បើ \(\displaystyle a_1, a_2, b_1, b_2\) ជាបួនចំនួនខុសពីសូន្យ គេថាគូ \(\displaystyle (a_1, a_2)\) និង \(\displaystyle (b_1, b_2)\) ជាគូសមាមាត្រគ្នា បើវាមានចំនួន \(\displaystyle k\) មួយដែល \(\displaystyle b_1 = ka_1\) និង \(\displaystyle b_2 = ka_2\) ។

លក្ខខណ្ឌនេះ គេអាចសរសេរ ៖

\[\frac{b_1}{a_1} = \frac{b_2}{a_2} \quad \text{ឬ} \quad \frac{a_1}{b_1} = \frac{a_2}{b_2}\]

ចំពោះ \(\displaystyle \frac{a_1}{b_1} = \frac{a_2}{b_2}\) បើគេគុណអង្គទាំងពីរនៃសមាមាត្រនឹង \(\displaystyle b_1 b_2\) គេបាន ៖

\[\frac{a_1}{b_1} \times b_1 b_2 = \frac{a_2}{b_2} \times b_1 b_2 \iff a_1 b_2 = a_2 b_1\]

ដូចនេះ ៖

\[\frac{a_1}{b_1} = \frac{a_2}{b_2} \iff a_1 b_2 = a_2 b_1\]

បើ \(\displaystyle k\) ជាតម្លៃរួមនៃផលធៀប \(\displaystyle \frac{b_1}{a_1}\) និង \(\displaystyle \frac{b_2}{a_2}\) គេបាន \(\displaystyle b_1 = ka_1\) និង \(\displaystyle b_2 = ka_2\)
ដូចនេះ \(\displaystyle \frac{b_1 + b_2}{a_1 + a_2} = \frac{k(a_1 + a_2)}{a_1 + a_2} = k\) ។ គេបានលក្ខណៈដូចខាងក្រោម ៖

\(\displaystyle a_1\) និង \(\displaystyle a_2\) ជាពីរចំនួនខុសពីសូន្យដែល \(\displaystyle a_1 + a_2 \neq 0\)
បើ \(\displaystyle \frac{b_1}{a_1} = \frac{b_2}{a_2}\) នោះគេបាន \(\displaystyle \frac{b_1}{a_1} = \frac{b_2}{a_2} = \frac{b_1 + b_2}{a_1 + a_2}\) ។
ដូចគ្នាដែរ \(\displaystyle a_1, a_2, a_3\) ជាបីចំនួនខុសពីសូន្យដែល \(\displaystyle a_1 + a_2 + a_3 \neq 0\)
បើ \(\displaystyle \frac{b_1}{a_1} = \frac{b_2}{a_2} = \frac{b_3}{a_3}\) នោះគេបាន \(\displaystyle \frac{b_1}{a_1} = \frac{b_2}{a_2} = \frac{b_3}{a_3} = \frac{b_1 + b_2 + b_3}{a_1 + a_2 + a_3}\) ។

លំហាត់គំរូ 1 ៖ រកថ្លៃទំនិញ \(\displaystyle 13~\text{kg}\) បើទំនិញ \(\displaystyle 6~\text{kg}\) ថ្លៃ \(\displaystyle 90~000~\text{៛}\) ។

ដំណោះស្រាយ
តាង \(\displaystyle x\) (រៀល) ជាថ្លៃទំនិញ \(\displaystyle 13~\text{kg}\) គេបានសមាមាត្រ ៖

\[\frac{x}{90~000} = \frac{13}{6} \implies x = \frac{13}{6} \times 90~000 = 195~000~\text{៛}\]

ដូចនេះ ទំនិញ \(\displaystyle 13~\text{kg}\) ថ្លៃ \(\displaystyle 195~000~\text{៛}\) ។

លំហាត់គំរូ 2 ៖ នាយកសាលាបានចំណាយប្រាក់ \(\displaystyle 120~000~\text{៛}\) ជូនរង្វាន់ដល់សិស្សពូកែបីនាក់ដែលជាប់ចំណាត់ថ្នាក់ពីលេខ 1 ដល់លេខ 3 ។ ចំនួនប្រាក់ដែលសិស្សម្នាក់ៗទទួលបានសមាមាត្រនឹង 3, 2 និង 1 រៀងគ្នា ។ រកប្រាក់ដែលសិស្សម្នាក់ៗទទួលបាន ។

ដំណោះស្រាយ
តាង \(\displaystyle a_1, a_2, a_3\) ជាចំនួនប្រាក់ដែលសិស្សម្នាក់ៗទទួលបានរៀងគ្នា ។
ដោយ \(\displaystyle a_1, a_2, a_3\) និង 3, 2, 1 សមាមាត្រគ្នា គេបាន ៖

\[\frac{a_1}{3} = \frac{a_2}{2} = \frac{a_3}{1} = \frac{a_1 + a_2 + a_3}{3 + 2 + 1} = \frac{120~000}{6} = 20~000~\text{៛}\]

គេទាញបាន ៖
\(\displaystyle a_1 = 20~000 \times 3 = 60~000~\text{៛}\)
\(\displaystyle a_2 = 20~000 \times 2 = 40~000~\text{៛}\)
\(\displaystyle a_3 = 20~000 \times 1 = 20~000~\text{៛}\)
ដូចនេះ សិស្សម្នាក់ៗដែលជាប់ចំណាត់ថ្នាក់លេខ 1 ដល់លេខ 3 ទទួលបានរង្វាន់រៀងគ្នាគឺ \(\displaystyle 60~000~\text{៛}, 40~000~\text{៛}, 20~000~\text{៛}\) ។

អត្រាប្តូរប្រាក់ ជាតម្លៃរូបិយវត្ថុរបស់ប្រទេសមួយធៀបនឹងរូបិយបណ្ណរបស់ប្រទេសដទៃទៀត ។

ឧទាហរណ៍ ៖ \(\displaystyle 4~050~\text{រៀល} = 1~\text{ដុល្លារអាមេរិក}\) ។

លំហាត់គំរូ 3 ៖ អត្រាប្តូរប្រាក់ 1 ដុល្លារអាមេរិកធៀបនឹងប្រាក់រៀលគឺ \(\displaystyle 4~050~\text{៛}\) ។ បើមីងយ៉ាប្តូរប្រាក់ \(\displaystyle 40~\$\) (ប្រាក់ដុល្លារអាមេរិក) តើគាត់ទទួលបានប្រាក់រៀលចំនួនប៉ុន្មាន?

ដំណោះស្រាយ
គណនាចំនួនប្រាក់រៀលដែលមីងយ៉ាទទួលបាន ៖
តាង \(\displaystyle x\) ជាចំនួនប្រាក់រៀល គេបានសមាមាត្រ ៖

\[\frac{1}{40} = \frac{4~050}{x} \implies 1 \times x = 40 \times 4~050 \implies x = 162~000~\text{៛}\]

ដូច្នេះមីងយ៉ាទទួលបានប្រាក់ \(\displaystyle 162~000~\text{៛}\) ពីការប្តូរប្រាក់ \(\displaystyle 40~\$\) ។

លំហាត់គំរូ 1 ៖ បុរស 10 នាក់អាចលើកឥដ្ឋមួយគំនរហើយក្នុងរយៈពេល 4 ម៉ោង ។ បើបុរស 5 នាក់លើកឥដ្ឋដដែលនោះ តើត្រូវប្រើពេលប៉ុន្មានទើបហើយ?

ដំណោះស្រាយ
តាង \(\displaystyle t\) (ម៉ោង) ជារយៈពេលដែលបុរស 5 នាក់លើកឥដ្ឋហើយ ។
ដោយចំនួនមនុស្សនិងរយៈពេលជាសមាមាត្រច្រាស គេបាន ៖

\[t : 4 = 10 : 5 \iff \frac{t}{4} = \frac{10}{5} \implies t = \frac{10}{5} \times 4 = 8\text{ ម៉ោង}\]

ដូចនេះ បុរស 5 នាក់ត្រូវប្រើរយៈពេល 8 ម៉ោងទើបលើកឥដ្ឋនោះហើយ ។

លំហាត់គំរូ 2 ៖ គេឱ្យ \(\displaystyle a : b : c = 3 : 5 : 9\) និង \(\displaystyle c - a = 72\) ។ រកតម្លៃនៃ \(\displaystyle a + b + c\) ។

ដំណោះស្រាយ
គេមាន \(\displaystyle \frac{a}{3} = \frac{b}{5} = \frac{c}{9} = \frac{a + b + c}{3 + 5 + 9} = \frac{a + b + c}{17}\)
ម្យ៉ាងទៀត \(\displaystyle \frac{c}{9} = \frac{a}{3} = \frac{c - a}{9 - 3} = \frac{c - a}{6}\)
គេបាន \(\displaystyle \frac{a + b + c}{17} = \frac{c - a}{6} \implies a + b + c = \frac{17}{6} \times (c - a) = \frac{17}{6} \times 72 = 204\) ។

ដំណោះស្រាយ
