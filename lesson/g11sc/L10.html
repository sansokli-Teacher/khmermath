1. រូបមន្តផលបូកនិងផលដក

1.1. \(\displaystyle \cos(\alpha\pm\beta)\)

ឧទាហរណ៍ : \(\displaystyle \cos(60^\circ - 30^\circ) = \cos30^\circ = \dfrac{\sqrt3}2 \approx 0.866\) តែ \(\displaystyle \cos60^\circ - \cos30^\circ = \dfrac{1-\sqrt3}{2} \approx -0.366\) ។ ដូច្នេះ \(\displaystyle \cos(\alpha - \beta) \ne \cos\alpha - \cos\beta\) ។ ដើម្បីរក \(\displaystyle \cos15^\circ\) (មុំមិនពិសេស) គេត្រូវការរូបមន្ត ។

ក្នុងរង្វង់ឯកតា \(\displaystyle \vec{OM} = (\cos\alpha, \sin\alpha)\) និង \(\displaystyle \vec{ON} = (\cos\beta, \sin\beta)\) ។ ផលគុណស្កាលែ ៖

\[\vec{OM}\cdot\vec{ON} = OM\cdot ON\cos(\beta-\alpha) = \cos(\beta - \alpha) = \cos(\alpha-\beta), \qquad \vec{OM}\cdot\vec{ON} = \cos\alpha\cos\beta + \sin\alpha\sin\beta\]
\[\begin{aligned} \cos(\alpha - \beta) &= \cos\alpha\cos\beta + \sin\alpha\sin\beta \qquad\text{(1)} \\ \cos(\alpha + \beta) &= \cos\alpha\cos\beta - \sin\alpha\sin\beta \qquad\text{(2)} \end{aligned}\]

(ទី ២ ពីទី ១ ដោយជំនួស \(\displaystyle \beta\) ដោយ \(\displaystyle -\beta\) ។)

ឧទាហរណ៍ : \(\displaystyle \cos15^\circ = \cos(60^\circ - 45^\circ) = \dfrac12\cdot\dfrac{\sqrt2}2 + \dfrac{\sqrt3}2\cdot\dfrac{\sqrt2}2 = \dfrac{\sqrt2+\sqrt6}{4}\) ;   \(\displaystyle \cos\dfrac{5\pi}{12} = \cos\left(\dfrac\pi4 + \dfrac\pi6\right) = \dfrac{\sqrt6-\sqrt2}{4}\) ។

1.2. \(\displaystyle \sin(\alpha\pm\beta)\)

ពី \(\displaystyle \sin(\alpha+\beta) = \cos\left[\left(\frac\pi2 - \alpha\right) - \beta\right]\) ហើយប្រើ (1) ។

\[\begin{aligned} \sin(\alpha + \beta) &= \sin\alpha\cos\beta + \cos\alpha\sin\beta \qquad\text{(3)} \\ \sin(\alpha - \beta) &= \sin\alpha\cos\beta - \cos\alpha\sin\beta \qquad\text{(4)} \end{aligned}\]

ឧទាហរណ៍ : \(\displaystyle \sin75^\circ = \dfrac{\sqrt6+\sqrt2}{4}\) ;   \(\displaystyle \sin\dfrac\pi{12} = \sin\left(\dfrac\pi4 - \dfrac\pi6\right) = \dfrac{\sqrt6 - \sqrt2}{4}\) ។

ដំណោះស្រាយ

\(\displaystyle \sin\alpha + \cos\alpha = \sqrt2\left(\sin\alpha\cos\frac\pi4 + \cos\alpha\sin\frac\pi4\right) = \sqrt2\sin\left(\alpha+\frac\pi4\right)\) ។

1.3. \(\displaystyle \tan(\alpha\pm\beta)\)

ចែក \(\displaystyle \tan(\alpha+\beta) = \dfrac{\sin\alpha\cos\beta + \cos\alpha\sin\beta}{\cos\alpha\cos\beta - \sin\alpha\sin\beta}\) នឹង \(\displaystyle \cos\alpha\cos\beta\) ៖

2. រូបមន្តមុំឌុប និងរូបមន្តកន្លះមុំ

2.1. រូបមន្តមុំឌុប

ដាក់ \(\displaystyle \beta = \alpha\) ក្នុងរូបមន្តផលបូក ៖

\[\begin{aligned} \sin2\alpha &= 2\sin\alpha\cos\alpha \qquad\text{(7)} \\ \cos2\alpha &= \cos^2\alpha - \sin^2\alpha = 1 - 2\sin^2\alpha = 2\cos^2\alpha - 1 \qquad\text{(8)} \\ \tan2\alpha &= \frac{2\tan\alpha}{1 - \tan^2\alpha} \qquad\text{(9)} \end{aligned}\]

ឧទាហរណ៍ 1 : \(\displaystyle \cos\alpha = -\dfrac45\) និង \(\displaystyle \dfrac\pi2 < \alpha < \pi\) ។ \(\displaystyle \sin\alpha = \dfrac35\) ដូច្នេះ \(\displaystyle \sin2\alpha = 2\cdot\dfrac35\cdot\left(-\dfrac45\right) = -\dfrac{24}{25}\), \(\displaystyle \cos2\alpha = 2\cdot\dfrac{16}{25} - 1 = \dfrac7{25}\), \(\displaystyle \tan2\alpha = -\dfrac{24}7\) ។

ឧទាហរណ៍ 2 : \(\displaystyle \sin3\alpha = \sin(2\alpha+\alpha) = 3\sin\alpha - 4\sin^3\alpha\) (10)   និង   \(\displaystyle \cos3\alpha = 4\cos^3\alpha - 3\cos\alpha\) (11) ។

គណនា \(\displaystyle \sin4x\) ។   ចម្លើយ \(\displaystyle \sin4x = \sin3x\cos x + \cos3x\sin x = 4\left(\cos^3x\sin x - \sin^3x\cos x\right)\) ។

✎ប្រតិបត្តិ

ស្រាយថា \(\displaystyle \dfrac{1 - 2\sin^2\alpha}{2\cot\left(\frac\pi4+\alpha\right)\cos^2\left(\frac\pi4-\alpha\right)} = 1\) ។   ចម្លើយ \(\displaystyle 1 - 2\sin^2\alpha = \cos2\alpha\) ហើយ \(\displaystyle 2\cot\left(\frac\pi4+\alpha\right)\cos^2\left(\frac\pi4-\alpha\right) = 2\tan\left(\frac\pi4-\alpha\right)\cos^2\left(\frac\pi4-\alpha\right) = \sin\left(\frac\pi2-2\alpha\right) = \cos2\alpha\) ។

2.2. រូបមន្តកន្លះមុំ

ជំនួស \(\displaystyle \alpha\) ដោយ \(\displaystyle \dfrac\alpha2\) ៖

\[\cos^2\frac\alpha2 = \frac{1 + \cos\alpha}{2},\quad \sin^2\frac\alpha2 = \frac{1 - \cos\alpha}{2},\quad \tan^2\frac\alpha2 = \frac{1 - \cos\alpha}{1 + \cos\alpha},\quad \tan\frac\alpha2 = \frac{\sin\alpha}{1 + \cos\alpha} \qquad\text{(12, 13)}\]

ហើយបើ \(\displaystyle t = \tan\dfrac\alpha2\) ៖    \(\displaystyle \sin\alpha = \dfrac{2t}{1+t^2},\quad \cos\alpha = \dfrac{1-t^2}{1+t^2},\quad \tan\alpha = \dfrac{2t}{1-t^2}\)   (14)

ឧទាហរណ៍ 1 : \(\displaystyle \sin22^\circ30' = \sqrt{\dfrac{1 - \cos45^\circ}{2}} = \dfrac{\sqrt{2-\sqrt2}}{2}\) ;   \(\displaystyle \sin\dfrac\pi{12} = \dfrac{\sqrt{2-\sqrt3}}{2}\) ;   \(\displaystyle \tan\dfrac{3\pi}8 = \dfrac{\sin\frac{3\pi}4}{1 + \cos\frac{3\pi}4} = \sqrt2 + 1\) ។

ឧទាហរណ៍ 2 : ផ្ទៀងផ្ទាត់ \(\displaystyle \dfrac{1 - \cos x}{\sin x} = \tan\dfrac x2\) ។ តាង \(\displaystyle t = \tan\dfrac x2\) ៖ \(\displaystyle \dfrac{1 - \frac{1-t^2}{1+t^2}}{\frac{2t}{1+t^2}} = \dfrac{2t^2}{2t} = t\) ។

\(\displaystyle \cos\alpha = -\dfrac35\) និង \(\displaystyle \dfrac\pi2 < \alpha < \pi\) ។ គណនា \(\displaystyle \sin\dfrac\alpha2\), \(\displaystyle \cos\dfrac\alpha2\) ។

3. រូបមន្តបម្លែង

3.1. ពីផលគុណទៅជាផលបូក

បូក/ដករូបមន្ត (1) ជាមួយ (2) និង (3) ជាមួយ (4) ៖

\[\begin{aligned} \cos\alpha\cos\beta &= \tfrac12[\cos(\alpha+\beta) + \cos(\alpha-\beta)] & \sin\alpha\sin\beta &= \tfrac12[\cos(\alpha-\beta) - \cos(\alpha+\beta)] \\ \sin\alpha\cos\beta &= \tfrac12[\sin(\alpha+\beta) + \sin(\alpha-\beta)] & \cos\alpha\sin\beta &= \tfrac12[\sin(\alpha+\beta) - \sin(\alpha-\beta)] \end{aligned}\]

ឧទាហរណ៍ : \(\displaystyle \cos75^\circ\cos45^\circ = \dfrac12(\cos120^\circ + \cos30^\circ) = \dfrac{\sqrt3-1}{4}\) ;   \(\displaystyle \sin\dfrac{5\pi}{12}\sin\dfrac\pi4 = \dfrac12\left[\cos\dfrac\pi6 - \cos\dfrac{2\pi}3\right] = \dfrac{\sqrt3+1}{4}\) ។

3.2. ពីផលបូកទៅជាផលគុណ

តាង \(\displaystyle \alpha + \beta = p\), \(\displaystyle \alpha - \beta = q\) ដូច្នេះ \(\displaystyle \alpha = \dfrac{p+q}2\), \(\displaystyle \beta = \dfrac{p-q}2\) ៖

\[\begin{aligned} \cos p + \cos q &= 2\cos\tfrac{p+q}2\cos\tfrac{p-q}2 & \cos p - \cos q &= -2\sin\tfrac{p+q}2\sin\tfrac{p-q}2 \\ \sin p + \sin q &= 2\sin\tfrac{p+q}2\cos\tfrac{p-q}2 & \sin p - \sin q &= 2\sin\tfrac{p-q}2\cos\tfrac{p+q}2 \\ \tan p \pm \tan q &= \frac{\sin(p\pm q)}{\cos p\cos q} & \cot p + \cot q &= \frac{\sin(p+q)}{\sin p\sin q},\quad \cot p - \cot q = \frac{\sin(q-p)}{\sin p\sin q} \end{aligned}\]
