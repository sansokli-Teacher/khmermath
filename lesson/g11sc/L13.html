មេរៀនទាំងអស់

១. សមីការត្រីកោណមាត្រ

១.១. សមីការលីនេអ៊ែរធៀបនឹងស៊ីនុស និងកូស៊ីនុស

ដើម្បីដោះស្រាយសមីការ \(\displaystyle a\cos x + b\sin x = c\) (\(\displaystyle a, b \ne 0\)) គេអាចប្រើវិធីពីរយ៉ាង៖

  • របៀបទី ១ (វិធីបម្លែងជាមុំតែមួយ)៖ ចែកអង្គទាំងពីរនឹង \(\displaystyle r = \sqrt{a^2 + b^2}\) ដោយតាង \(\displaystyle \cos\theta = \frac{a}{r}\), \(\displaystyle \sin\theta = \frac{b}{r}\) នោះសមីការក្លាយជា

    \[\cos(x - \theta) = \frac{c}{r}.\]

    សមីការមានចម្លើយលុះត្រាតែ \(\displaystyle |c| \le \sqrt{a^2 + b^2}\) (ឬ \(\displaystyle a^2 + b^2 \ge c^2\))។

  • របៀបទី ២ (វិធី \(\displaystyle t = \tan\frac{x}{2}\))៖ ពិនិត្យជាមុនថាតើ \(\displaystyle x = \pi + 2k\pi\) ជាឫសឬទេ រួចជំនួស \(\displaystyle \cos x = \frac{1-t^2}{1+t^2}\), \(\displaystyle \sin x = \frac{2t}{1+t^2}\) បាន \(\displaystyle (c+a)t^2 - 2bt + c - a = 0\)។

ដោះស្រាយសមីការ \(\displaystyle \sqrt{3}\sin 2x + \cos 2x = \sqrt{2}\)។

មើលដំណោះស្រាយ

មាន \(\displaystyle r = \sqrt{1+3} = 2\) ចែកអង្គទាំងពីរនឹង \(\displaystyle 2\)៖

\[\frac{1}{2}\cos 2x + \frac{\sqrt{3}}{2}\sin 2x = \frac{\sqrt{2}}{2} \iff \cos\left(2x - \frac{\pi}{3}\right) = \cos\frac{\pi}{4}.\]

ដូច្នេះ \(\displaystyle 2x - \frac{\pi}{3} = \pm\frac{\pi}{4} + 2k\pi \implies x = \frac{7\pi}{24} + k\pi\) ឬ \(\displaystyle x = \frac{\pi}{24} + k\pi\) (\(\displaystyle k \in \mathbb{Z}\))។ ចុងចម្លើយលើរង្វង់មាន ៤។

▶ មើលរបៀបគូសរូបនេះ

១.២. សមីការដឺក្រេទី ២ ធៀបនឹងអនុគមន៍ត្រីកោណមាត្រ

បំប្លែងសមីការឱ្យមានអនុគមន៍ត្រីកោណមាត្រតែមួយ តាង \(\displaystyle t\) ជាអនុគមន៍នោះ (ជាមួយលក្ខខណ្ឌ \(\displaystyle -1 \le t \le 1\) ចំពោះ \(\displaystyle \sin x, \cos x\)) រួចដោះស្រាយសមីការដឺក្រេទី ២ និងពិនិត្យលក្ខខណ្ឌកំណត់។

ដោះស្រាយសមីការ \(\displaystyle \frac{\cos x(2\sin x + 3\sqrt{2}) - 2\cos^2 x - 1}{1 + \sin 2x} = 1\)។

មើលដំណោះស្រាយ

លក្ខខណ្ឌកំណត់ \(\displaystyle 1 + \sin 2x \ne 0 \iff x \ne -\frac{\pi}{4} + k\pi\)។ បំប្លែងបាន \(\displaystyle 2\cos^2 x - 3\sqrt{2}\cos x + 2 = 0 \implies \cos x = \frac{1}{\sqrt{2}}\) (ព្រោះ \(\displaystyle \sqrt{2} > 1\)) នាំឱ្យ \(\displaystyle x = \pm\frac{\pi}{4} + 2k\pi\)។ ច្រានចោល \(\displaystyle -\frac{\pi}{4} + 2k\pi\) តាមលក្ខខណ្ឌ បាន \(\displaystyle x = \frac{\pi}{4} + 2k\pi\) (\(\displaystyle k \in \mathbb{Z}\))។

២. សមីការសមលក្ខណៈដឺក្រេទី ២

ចំពោះសមីការរាង \(\displaystyle a\sin^2 x + b\sin x\cos x + c\cos^2 x = d\)៖

  1. ពិនិត្យករណី \(\displaystyle \cos x = 0\) (\(\displaystyle x = \frac{\pi}{2} + k\pi\)) ថាតើផ្ទៀងផ្ទាត់សមីការឬទេ។

  2. បើ \(\displaystyle \cos x \ne 0\) ចែកអង្គទាំងពីរនឹង \(\displaystyle \cos^2 x\) ដោយប្រើ \(\displaystyle \frac{1}{\cos^2 x} = 1 + \tan^2 x\) ដើម្បីទទួលបានសមីការដឺក្រេទី ២ ធៀបនឹង \(\displaystyle \tan x\)៖

    \[(a - d)\tan^2 x + b\tan x + (c - d) = 0.\]

ដោះស្រាយសមីការ \(\displaystyle 3\sin^2 x + 2\sin x\cos x = 2\) និងរកតម្លៃ \(\displaystyle m\) ឱ្យ \(\displaystyle \sin 4x = m\tan x\) មានឫស (\(\displaystyle x \ne k\pi\))។

មើលដំណោះស្រាយ

ក. បើ \(\displaystyle \cos x = 0 \implies 3 \ne 2\) (មិនយក)។ ចែកនឹង \(\displaystyle \cos^2 x\)៖ \(\displaystyle 3\tan^2 x + 2\tan x = 2(1+\tan^2 x) \implies \tan^2 x + 2\tan x - 2 = 0 \implies \tan x = -1 \pm \sqrt{3}\)។
ខ. លក្ខខណ្ឌ \(\displaystyle \cos x \ne 0, \sin x \ne 0\)។ \(\displaystyle \sin 4x = 4\sin x\cos x\cos 2x = m\frac{\sin x}{\cos x} \implies 4\cos^2 x\cos 2x = m \implies 2(1+\cos 2x)\cos 2x = m\)។ តាង \(\displaystyle t = \cos 2x \in (-1, 1)\) (ព្រោះ \(\displaystyle \sin 2x \ne 0\)) នោះ \(\displaystyle m = 2t^2 + 2t = 2\left(t + \frac{1}{2}\right)^2 - \frac{1}{2}\)។ ដូច្នេះ \(\displaystyle -\frac{1}{2} \le m < 4\)។

៣. ប្រព័ន្ធសមីការត្រីកោណមាត្រ

ដើម្បីដោះស្រាយប្រព័ន្ធសមីការត្រីកោណមាត្រ គេប្រើរូបមន្តបំប្លែងផលបូកជាផលគុណ ឬប្តូរអញ្ញាត \(\displaystyle u = x + y, v = x - y\) ឬ \(\displaystyle \tan x, \tan y\) រួចរកចម្លើយទូទៅ។

ដោះស្រាយប្រព័ន្ធសមីការ \(\displaystyle \begin{cases} \cos^2 x + \cos^2 y = \frac{1}{4} \\ x + y = \frac{5\pi}{6} \end{cases}\)។

មើលដំណោះស្រាយ

ប្រើ \(\displaystyle \cos^2 x = \frac{1+\cos 2x}{2}\)៖ \(\displaystyle 1 + \frac{\cos 2x + \cos 2y}{2} = \frac{1}{4} \implies \cos(x+y)\cos(x-y) = -\frac{3}{4}\)។
ជំនួស \(\displaystyle \cos\frac{5\pi}{6} = -\frac{\sqrt{3}}{2}\) បាន \(\displaystyle \cos(x-y) = \frac{\sqrt{3}}{2} \implies x - y = \pm\frac{\pi}{6} + 2k\pi\)។
ផ្គុំជាមួយ \(\displaystyle x + y = \frac{5\pi}{6}\) បាន \(\displaystyle \left(x = \frac{\pi}{2} + k\pi, y = \frac{\pi}{3} - k\pi\right)\) ឬ \(\displaystyle \left(x = \frac{\pi}{3} + k\pi, y = \frac{\pi}{2} - k\pi\right)\) (\(\displaystyle k \in \mathbb{Z}\))។

៤. វិសមីការត្រីកោណមាត្រ

ចំពោះវិសមីការប្រភាគ ឬដឺក្រេទី ២ គេសិក្សាសញ្ញាលើតារាងសញ្ញា ឬលើរង្វង់ត្រីកោណមាត្រ ដោយកំណត់ដែនកំណត់ជាមុន។ ចំពោះវិសមីការក្នុងត្រីកោណ \(\displaystyle ABC\) (\(\displaystyle A+B+C=\pi\)) គេប្រើរូបមន្តបម្លែង និងសញ្ញាក្នុងចន្លោះ \(\displaystyle (0, \pi)\)។

▶ មើលរបៀបគូសរូបនេះ

ដោះស្រាយវិសមីការ៖ ក. \(\displaystyle \frac{2\sin x - 1}{\sin x} \le 0\) និង ខ. \(\displaystyle 2\sin^2\left(x + \frac{\pi}{4}\right) + \sqrt{3}\cos 2x > 0\)។

មើលដំណោះស្រាយ

ក. លក្ខខណ្ឌ \(\displaystyle \sin x \ne 0\)។ វិភាគសញ្ញាប្រភាគបាន \(\displaystyle 0 < \sin x \le \frac{1}{2}\) ដូច្នេះ \(\displaystyle 2k\pi < x \le \frac{\pi}{6} + 2k\pi\) ឬ \(\displaystyle \frac{5\pi}{6} + 2k\pi \le x < \pi + 2k\pi\) (\(\displaystyle k \in \mathbb{Z}\))។
ខ. \(\displaystyle 1 - \cos\left(2x + \frac{\pi}{2}\right) + \sqrt{3}\cos 2x > 0 \iff 1 + \sin 2x + \sqrt{3}\cos 2x > 0 \iff \sin\left(2x + \frac{\pi}{3}\right) > -\frac{1}{2}\)។
ដូច្នេះ \(\displaystyle -\frac{\pi}{6} + 2k\pi < 2x + \frac{\pi}{3} < \frac{7\pi}{6} + 2k\pi \implies -\frac{\pi}{4} + k\pi < x < \frac{5\pi}{12} + k\pi\) (\(\displaystyle k \in \mathbb{Z}\))។

▶ មើលរបៀបគូសរូបនេះ
▶ មើលរូបមានចលនា៖ បន្ទាត់ប៉ះត្រង់ចំណុចមួយនៃរង្វង់

បង្ហាញថាក្នុងត្រីកោណ \(\displaystyle ABC\) គេបាន \(\displaystyle \cos A + \cos B + \cos C \le \frac{3}{2}\)។

មើលដំណោះស្រាយ

\(\displaystyle \frac{3}{2} - (\cos A + \cos B + \cos C) = \frac{1}{2}\left[1 - 4\sin\frac{C}{2}\cos\frac{A-B}{2} + 4\sin^2\frac{C}{2}\right] = \frac{1}{2}\left[\left(2\sin\frac{C}{2} - \cos\frac{A-B}{2}\right)^2 + \sin^2\frac{A-B}{2}\right] \ge 0\)។

លំហាត់អនុវត្ត
