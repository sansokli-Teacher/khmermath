1.3.2. អ៊ីប៉ូតេនុសប៉ុនគ្នានិងជ្រុងមុំកែងមួយប៉ុនគ្នា (អ.ជ)

•ឧទាហរណ៍

ក្នុង \(\displaystyle \Delta ABC\) និង \(\displaystyle \Delta A'B'C'\) មាន \(\displaystyle \angle A = \angle A' = 90^\circ\), \(\displaystyle AB = A'B'\), \(\displaystyle BC = B'C'\)។ តើត្រីកោណកែងទាំងពីរនេះប៉ុនគ្នាឬទេ?

ដោយ \(\displaystyle AB = A'B'\) យើងអាចត្រឡប់ ហើយដាក់ជ្រុង \(\displaystyle A'C'\) ត្រួតលើជ្រុង \(\displaystyle AC\) ដែលជាជ្រុងនៃ \(\displaystyle \Delta A'B'C'\) និង \(\displaystyle \Delta ABC\)។

ដោយ \(\displaystyle \angle A = \angle A' = 90^\circ\) យើងដឹងថា \(\displaystyle \angle BAB' = \angle BAC + \angle CAB' = 90^\circ + 90^\circ = 180^\circ\) ជាមុំជាប់បន្ថែម។

ដូច្នេះអង្កត់ \(\displaystyle BA\) និងអង្កត់ \(\displaystyle AB'\) ភ្ជាប់គ្នាបានអង្កត់ \(\displaystyle BB'\) មួយ។

ក្នុង \(\displaystyle \Delta BCB'\) មាន \(\displaystyle CB = CB'\) នោះ \(\displaystyle \Delta BCB'\) ជាត្រីកោណសមបាតត្រង់កំពូល \(\displaystyle C\)។ ដូច្នេះ \(\displaystyle \angle B = \angle B'\)។

ក្នុងត្រីកោណកែង \(\displaystyle BAC\) និង \(\displaystyle B'AC\) មាន

  • \(\displaystyle CB = CB'\) អ៊ីប៉ូតេនុសប៉ុនគ្នា (សម្មតិកម្ម)
  • \(\displaystyle \angle B = \angle B'\) មុំប៉ុនគ្នា

ដូច្នេះ \(\displaystyle \Delta ABC \cong \Delta A'B'C'\) (តាមលក្ខខណ្ឌ អ.ម)។

    ដូចនេះ \(\displaystyle \Delta PQR \cong \Delta RSQ\) (តាមលក្ខខណ្ឌ ជ.ម.ជ) ។

    ខ. រកប្រវែង \(\displaystyle QS\) និង \(\displaystyle \angle QPR\) ៖

    ដោយ \(\displaystyle \Delta PQR \cong \Delta RSQ\) នោះធាតុត្រូវគ្នាប៉ុនរៀងគ្នា ៖

    • ជ្រុងត្រូវគ្នា ៖ \(\displaystyle QS = PR = 5\text{ cm}\)

    • មុំត្រូវគ្នា ៖ \(\displaystyle \angle QPR = \angle RSQ\) ។ ដោយ \(\displaystyle \angle QSR = 50^\circ\) (មុំ \(\displaystyle \angle RSQ = 50^\circ\)) នោះ ៖

      \[\angle QPR = 50^\circ\]

    ដូចនេះ \(\displaystyle QS = 5\text{ cm}\) និង \(\displaystyle \angle QPR = 50^\circ\) ។

  34. \(\displaystyle ABCD\) ជាប្រលេឡូក្រាម (ប្រើបីរបៀបខុសៗគ្នា) ដើម្បីស្រាយបំភ្លឺថា \(\displaystyle \Delta ABC\) និង \(\displaystyle \Delta CDA\) ប៉ុនគ្នា។

    មើលដំណោះស្រាយ

    ដោយ \(\displaystyle ABCD\) ជាប្រលេឡូក្រាម នោះគេមានជ្រុងឈមស្របគ្នានិងប៉ុនគ្នា (\(\displaystyle AB \parallel CD\), \(\displaystyle AD \parallel BC\), \(\displaystyle AB = CD\), \(\displaystyle AD = BC\)) និងមុំឈមប៉ុនគ្នា (\(\displaystyle \angle B = \angle D\), \(\displaystyle \angle A = \angle C\)) ។

    ស្រាយបញ្ជាក់ថា \(\displaystyle \Delta ABC \cong \Delta CDA\) តាមបីរបៀប ៖

    របៀបទី 1 (ករណី ជ.ជ.ជ) ៖

    • \(\displaystyle AB = CD\) (ជ្រុងឈមនៃប្រលេឡូក្រាម)
    • \(\displaystyle BC = DA\) (ជ្រុងឈមនៃប្រលេឡូក្រាម)
    • \(\displaystyle AC\) ជាជ្រុងរួម

    ដូចនេះ \(\displaystyle \Delta ABC \cong \Delta CDA\) (តាមលក្ខខណ្ឌ ជ.ជ.ជ) ។

    របៀបទី 2 (ករណី ជ.ម.ជ) ៖

    • \(\displaystyle AB = CD\) (ជ្រុងឈមនៃប្រលេឡូក្រាម)
    • \(\displaystyle \angle B = \angle D\) (មុំឈមនៃប្រលេឡូក្រាម)
    • \(\displaystyle BC = DA\) (ជ្រុងឈមនៃប្រលេឡូក្រាម)

    ដូចនេះ \(\displaystyle \Delta ABC \cong \Delta CDA\) (តាមលក្ខខណ្ឌ ជ.ម.ជ) ។

    របៀបទី 3 (ករណី ម.ជ.ម) ៖

    • \(\displaystyle \angle BAC = \angle DCA\) (មុំឆ្លាស់ក្នុង ព្រោះ \(\displaystyle AB \parallel CD\))
    • \(\displaystyle AC\) ជាជ្រុងរួម
    • \(\displaystyle \angle BCA = \angle DAC\) (មុំឆ្លាស់ក្នុង ព្រោះ \(\displaystyle BC \parallel AD\))

    ដូចនេះ \(\displaystyle \Delta ABC \cong \Delta CDA\) (តាមលក្ខខណ្ឌ ម.ជ.ម) ។
