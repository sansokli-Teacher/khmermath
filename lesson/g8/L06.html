\[\frac{1-x}{x^2+x-2} = \frac{-(x-1)}{(x-1)(x+2)} = -\frac{1}{x+2}\]
Tជាទូទៅ

ដើម្បីសម្រួលកន្សោមសនិទាន គេត្រូវដាក់ភាគយកនិងភាគបែងជាផលគុណកត្តា ហើយចែកភាគយកនិងភាគបែងនឹងកត្តារួមខុសពីសូន្យ ។

\[\text{បើ } \frac{A}{B} \text{ ជាកន្សោមសនិទាន នោះ } \frac{AK}{BK} = \frac{A}{B} \quad (K \ne 0)\]
១លំហាត់គំរូ ១

សម្រួលកន្សោមសនិទាន \(\displaystyle \frac{(x-3)(3x+1)-(2x-6)(x+1)}{1-x^2}\) ។

ដំណោះស្រាយ ៖

\[\begin{aligned} \frac{(x-3)(3x+1)-(2x-6)(x+1)}{1-x^2} &= \frac{(x-3)(3x+1)-2(x-3)(x+1)}{-(x^2-1)} \\ &= \frac{(x-3)[(3x+1)-2(x+1)]}{-(x-1)(x+1)} \\ &= \frac{(x-3)(3x+1-2x-2)}{-(x-1)(x+1)} \\ &= \frac{(x-3)(x-1)}{-(x-1)(x+1)} = -\frac{x-3}{x+1} \end{aligned}\]
២លំហាត់គំរូ ២

រង្វង់មួយចារឹកក្នុងការេដែលជ្រុងមានរង្វាស់ស្មើនឹង \(\displaystyle x\) ។ គណនាផលធៀបរវាងផ្ទៃក្រឡានៃរង្វង់និងការេ ។

ដំណោះស្រាយ ៖
រង្វង់មានកាំស្មើនឹង \(\displaystyle r = \frac{x}{2}\) ។
ផ្ទៃក្រឡារង្វង់គឺ \(\displaystyle \mathcal{A}_{\text{រង្វង់}} = \pi\left(\frac{x}{2}\right)^2 = \frac{\pi}{4}x^2\) និងផ្ទៃក្រឡាការេគឺ \(\displaystyle \mathcal{A}_{\text{ការេ}} = x^2\) ។
ផលធៀបរវាងផ្ទៃក្រឡារង្វង់និងការេគឺ ៖

\[\frac{\frac{\pi}{4}x^2}{x^2} = \frac{\pi}{4}\]
✎ប្រតិបត្តិ

4. វិធីគុណនិងចែកកន្សោមសនិទាន

4.1. វិធីគុណកន្សោមសនិទាន

ដូចគ្នានឹងវិធីគុណចំនួនសនិទានដែរ ៖

\[\frac{3}{4} \times \frac{2}{5} = \frac{3 \times 2}{4 \times 5} = \frac{6}{20} = \frac{3}{10}\]

ឧទាហរណ៍ 1 ៖ រកផលគុណរួចសម្រួល \(\displaystyle \frac{7b}{10a} \times \frac{5a^2}{8b}\)

\[\frac{7b}{10a} \times \frac{5a^2}{8b} = \frac{35a^2b}{80ab} = \frac{5ab \cdot 7a}{5ab \cdot 16} = \frac{7a}{16}\]

ឧទាហរណ៍ 2 ៖ រកផលគុណរួចសម្រួល \(\displaystyle \frac{5x}{4x-12} \times \frac{2x^2-6x}{3}\)

\[\frac{5x}{4(x-3)} \times \frac{2x(x-3)}{3} = \frac{10x^2(x-3)}{12(x-3)} = \frac{5x^2}{6}\]
Tជាទូទៅ

ដើម្បីគុណកន្សោមសនិទាន គេត្រូវ ៖

  1. ដាក់ភាគយកនិងភាគបែងជាផលគុណកត្តា (បើអាច)
  2. គុណភាគយកនិងភាគយក ហើយភាគបែងគុណនឹងភាគបែង
  3. សម្រួលភាគយកនិងភាគបែងនឹងកត្តារួម ។

បើ \(\displaystyle \frac{A}{B}\) និង \(\displaystyle \frac{C}{D}\) ជាពីរកន្សោមសនិទាន គេបាន \(\displaystyle \frac{A}{B} \times \frac{C}{D} = \frac{AC}{BD}\) (\(\displaystyle B \ne 0, D \ne 0\)) ។

១លំហាត់គំរូ ១

គណនាផលគុណ ៖

  1. ក. \(\displaystyle \frac{a^2-2a+1}{a^2-1} \times \frac{a^2+a}{a^2-2a}\)
  2. ខ. \(\displaystyle \frac{m^2+6m+9}{(a+2b)^2} \times \frac{7a+14b}{m+3}\)

ដំណោះស្រាយ ៖

  1. ក. \(\displaystyle \frac{(a-1)^2}{(a-1)(a+1)} \times \frac{a(a+1)}{a(a-2)} = \frac{a(a-1)^2(a+1)}{a(a-1)(a+1)(a-2)} = \frac{a-1}{a-2}\)
  2. ខ. \(\displaystyle \frac{(m+3)^2}{(a+2b)^2} \times \frac{7(a+2b)}{m+3} = \frac{7(m+3)^2(a+2b)}{(a+2b)^2(m+3)} = \frac{7(m+3)}{a+2b}\)
✎ប្រតិបត្តិ

គណនាផលគុណ ៖

  1. ក. \(\displaystyle \frac{9a^2-6a+1}{5-a} \times \frac{5(a-2)-a(a-2)}{a^2-4a+4}\)
  2. ខ. \(\displaystyle (3x+3) \times \frac{x+4}{x^2+5x+4}\)

ចម្លើយ ៖

  1. ក. \(\displaystyle \frac{(3a-1)^2}{5-a} \times \frac{(a-2)(5-a)}{(a-2)^2} = \frac{(3a-1)^2}{a-2}\)
  2. ខ. \(\displaystyle 3(x+1) \times \frac{x+4}{(x+1)(x+4)} = 3\)

4.2. វិធីចែកកន្សោមសនិទាន

ដូចគ្នានឹងវិធីចែកចំនួនសនិទានដែរ \(\displaystyle \frac{3}{2} \div \frac{2}{5} = \frac{3}{2} \times \frac{5}{2} = \frac{15}{4}\) ។

ឧទាហរណ៍ ៖ រកផលចែកកន្សោមសនិទានខាងក្រោម ៖

  1. ក. \(\displaystyle \frac{4x^2}{15y} \div \frac{3x}{10y^2} = \frac{4x^2}{15y} \times \frac{10y^2}{3x} = \frac{40x^2y^2}{45xy} = \frac{8xy}{9}\)
  2. ខ. \(\displaystyle \frac{a^2-9}{3a} \div \frac{a+3}{a-3} = \frac{(a-3)(a+3)}{3a} \times \frac{a-3}{a+3} = \frac{(a-3)^2}{3a}\)
Tជាទូទៅ

ដើម្បីចែកកន្សោមសនិទាន គេគុណប្រភាគតំណាងចែកនឹងចម្រាសនៃប្រភាគតួចែក រួចធ្វើតាមវិធីគុណនៃកន្សោមសនិទាន ។

\[\frac{A}{B} \div \frac{C}{D} = \frac{A}{B} \times \frac{D}{C} = \frac{A \cdot D}{B \cdot C} \quad (B \ne 0, C \ne 0, D \ne 0)\]
១លំហាត់គំរូ ១

គណនាផលចែកកន្សោមសនិទានខាងក្រោម ៖

  1. ក. \(\displaystyle \frac{a+3}{b^2+4b+4} \div \frac{2a+6}{b+2}\)
  2. ខ. \(\displaystyle \frac{4x^2+8x}{x^2-9} \div \frac{6x^3+12x^2}{x^2-2x-3}\)

ដំណោះស្រាយ ៖

  1. ក. \(\displaystyle \frac{a+3}{(b+2)^2} \times \frac{b+2}{2(a+3)} = \frac{(a+3)(b+2)}{2(b+2)^2(a+3)} = \frac{1}{2(b+2)}\)
  2. ខ. \(\displaystyle \frac{4x(x+2)}{(x-3)(x+3)} \times \frac{(x-3)(x+1)}{6x^2(x+2)} = \frac{4x(x+2)(x-3)(x+1)}{6x^2(x+2)(x-3)(x+3)} = \frac{2(x+1)}{3x(x+3)}\)
✎ប្រតិបត្តិ

គណនាផលចែកកន្សោមសនិទានខាងក្រោម ៖

  1. ក. \(\displaystyle \frac{4x+8}{x+3} \div (x+2)\)
  2. ខ. \(\displaystyle \frac{x-y}{x^2-y^2} \div \frac{x+y}{x^2+2xy+y^2}\)
  3. គ. \(\displaystyle \frac{3p-5q}{4p^2-q^2} \div \frac{5q-3p}{8p^2-4pq}\)
  4. ឃ. \(\displaystyle \frac{4a^3b^2}{3a^2+5a} \div \frac{6a^5b^7}{3a^2+17a+20}\)

ចម្លើយ ៖

  1. ក. \(\displaystyle \frac{4(x+2)}{x+3} \times \frac{1}{x+2} = \frac{4}{x+3}\)
  2. ខ. \(\displaystyle \frac{x-y}{(x-y)(x+y)} \times \frac{(x+y)^2}{x+y} = \frac{1}{x+y} \times (x+y) = 1\)
  3. គ. \(\displaystyle \frac{3p-5q}{(2p-q)(2p+q)} \times \frac{4p(2p-q)}{-(3p-5q)} = -\frac{4p}{2p+q}\)
  4. ឃ. \(\displaystyle \frac{4a^3b^2}{a(3a+5)} \times \frac{(3a+5)(a+4)}{6a^5b^7} = \frac{2(a+4)}{3a^3b^5}\)

5. វិធីបូកនិងដកកន្សោមសនិទាន

5.1. ករណីមានភាគបែងដូចគ្នា

ឧទាហរណ៍ ៖ រកផលបូកនិងផលដកកន្សោមសនិទានខាងក្រោម ៖

  1. ក. \(\displaystyle \frac{5}{a} + \frac{7}{a} = \frac{5+7}{a} = \frac{12}{a}\)
  2. ខ. \(\displaystyle \frac{3y-2}{y-5} + \frac{8y+7}{y-5} = \frac{3y-2+8y+7}{y-5} = \frac{11y+5}{y-5}\)
  3. គ. \(\displaystyle \frac{3x}{(x-1)(x-2)} - \frac{6}{(x-1)(x-2)} = \frac{3x-6}{(x-1)(x-2)} = \frac{3(x-2)}{(x-1)(x-2)} = \frac{3}{x-1}\)
Tជាទូទៅ

ចំពោះកន្សោមសនិទានដែលមានភាគបែងដូចគ្នា ៖

\[\frac{A}{B} + \frac{C}{B} = \frac{A+C}{B} \quad \text{និង} \quad \frac{A}{B} - \frac{C}{B} = \frac{A-C}{B} \quad (B \ne 0)\]
១លំហាត់គំរូ ១

គណនា ៖

  1. ក. \(\displaystyle \frac{2}{x-3} + \frac{7}{3-x}\)
  2. ខ. \(\displaystyle \frac{a}{2a+3} - \frac{a-3}{2a+3}\)

ដំណោះស្រាយ ៖

  1. ក. \(\displaystyle \frac{2}{x-3} - \frac{7}{x-3} = \frac{2-7}{x-3} = -\frac{5}{x-3}\)
  2. ខ. \(\displaystyle \frac{a-(a-3)}{2a+3} = \frac{a-a+3}{2a+3} = \frac{3}{2a+3}\)
✎ប្រតិបត្តិ

គណនា ៖

  1. ក. \(\displaystyle \frac{t^2}{t+4} + \frac{4t}{t+4}\)
  2. ខ. \(\displaystyle \frac{5x}{x-y} - \frac{5y}{y-x}\)

ចម្លើយ ៖

  1. ក. \(\displaystyle \frac{t^2+4t}{t+4} = \frac{t(t+4)}{t+4} = t\)
  2. ខ. \(\displaystyle \frac{5x}{x-y} + \frac{5y}{x-y} = \frac{5(x+y)}{x-y}\)

5.2. ករណីមានភាគបែងមិនដូចគ្នា

ដើម្បីឱ្យវិធីបូកនិងដកអាចប្រព្រឹត្តិទៅបាន គេត្រូវធ្វើឱ្យមានភាគបែងរួម ។

ឧទាហរណ៍ ៖ គណនាផលបូកនិងដកនៃកន្សោមសនិទាន ៖

  1. ក. \(\displaystyle \frac{y}{2x} + \frac{x}{3y} = \frac{y \cdot 3y}{2x \cdot 3y} + \frac{x \cdot 2x}{3y \cdot 2x} = \frac{3y^2+2x^2}{6xy}\)   (ភាគបែងរួមតូចបំផុតគឺ \(\displaystyle 6xy\))
  2. ខ. \(\displaystyle \frac{4}{n} - \frac{2}{n+1} = \frac{4(n+1)-2n}{n(n+1)} = \frac{4n+4-2n}{n(n+1)} = \frac{2n+4}{n(n+1)} = \frac{2(n+2)}{n(n+1)}\)
Tជាទូទៅ

ដើម្បីបូកឬដកកន្សោមសនិទានដែលមានភាគបែងមិនដូចគ្នា គេត្រូវ ៖

  1. រកភាគបែងរួមតូចបំផុត (LCM)
  2. ប្តូរប្រភាគនីមួយៗដោយប្រភាគសមមូលដែលមានភាគបែងរួមតូចបំផុត
  3. បូក ឬដកភាគយកដោយរក្សាភាគបែងរួមតូចបំផុតឱ្យនៅដដែល
  4. សម្រួលលទ្ធផល (បើអាច) ។
១លំហាត់គំរូ ១

គណនា \(\displaystyle \frac{t+1}{t^2+5t} + \frac{8}{t^2-25}\) ។

ដំណោះស្រាយ ៖

\[\begin{aligned} \frac{t+1}{t(t+5)} + \frac{8}{(t-5)(t+5)} &= \frac{(t+1)(t-5)+8t}{t(t+5)(t-5)} \\ &= \frac{t^2-4t-5+8t}{t(t+5)(t-5)} \\ &= \frac{t^2+4t-5}{t(t+5)(t-5)} \\ &= \frac{(t+5)(t-1)}{t(t+5)(t-5)} = \frac{t-1}{t(t-5)} \end{aligned}\]
២លំហាត់គំរូ ២

បង្ហាញថា \(\displaystyle \frac{1}{n} - \frac{1}{n+1} = \frac{1}{n(n+1)}\) រួចគណនាផលបូក \(\displaystyle S = \frac{1}{1 \times 2} + \frac{1}{2 \times 3} + \frac{1}{3 \times 4} + \frac{1}{4 \times 5}\) ។

ដំណោះស្រាយ ៖

\[\frac{1}{n} - \frac{1}{n+1} = \frac{(n+1)-n}{n(n+1)} = \frac{1}{n(n+1)}\]

តាមរូបមន្តនេះ ចំពោះ \(\displaystyle n = 1, 2, 3, 4\) គេបាន ៖

\[\begin{aligned} S &= \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{4}\right) + \left(\frac{1}{4} - \frac{1}{5}\right) \\ &= 1 - \frac{1}{5} = \frac{4}{5} \end{aligned}\]
✎ប្រតិបត្តិ

គណនា ៖

  1. ក. \(\displaystyle \frac{2m}{m-5} + \frac{12}{m^2-25}\)
  2. ខ. \(\displaystyle \frac{1}{x-1} + \frac{1}{3x} - \frac{1}{x^2(x-1)}\)
  3. គ. \(\displaystyle \frac{a^2-1}{a^2-2a-15} - \frac{a+2}{a+3}\)
  4. ឃ. \(\displaystyle \frac{x^2+6x+9}{x^2+3x} + \frac{x^2-x-2}{x^2-4}\)

ចម្លើយ ៖

  1. ក. \(\displaystyle \frac{2m(m+5)+12}{(m-5)(m+5)} = \frac{2m^2+10m+12}{m^2-25}\)
  2. ខ. \(\displaystyle \frac{3x^2+x(x-1)-3}{3x^2(x-1)} = \frac{4x^2-x-3}{3x^2(x-1)} = \frac{(x-1)(4x+3)}{3x^2(x-1)} = \frac{4x+3}{3x^2}\)

គេដឹងថាបំពង់ទឹកទី 1 អាចបង្ហូរទឹកដាក់អាងមួយតែឯងពេញប្រើអស់រយៈពេល \(\displaystyle t_1\) ម៉ោង ហើយបំពង់ទឹកទី 2 បង្ហូរទឹកដាក់អាងដដែលតែឯងពេញ ប្រើអស់រយៈពេល \(\displaystyle t_2\) ម៉ោង ។ ចូរបញ្ជាក់ថាបំពង់ទឹកទាំងពីរបង្ហូរទឹកដាក់អាងនោះ រួមគ្នាប្រើអស់រយៈពេល \(\displaystyle \frac{t_1 t_2}{t_1 + t_2}\) ម៉ោង ។

ដំណោះស្រាយ ៖
តាង \(\displaystyle c\) ជាចំណុះនៃអាងទឹក ។
ក្នុង 1 ម៉ោង បំពង់ទី 1 បង្ហូរទឹកបាន \(\displaystyle \frac{c}{t_1}\) និងបំពង់ទី 2 បង្ហូរបាន \(\displaystyle \frac{c}{t_2}\) ។
ក្នុង 1 ម៉ោង បំពង់ទាំងពីរបង្ហូរទឹកចូលអាងរួមគ្នាបាន ៖

\[\frac{c}{t_1} + \frac{c}{t_2} = c\left(\frac{1}{t_1} + \frac{1}{t_2}\right) = c\left(\frac{t_1+t_2}{t_1 t_2}\right)\]

ដើម្បីបង្ហូរទឹកឱ្យបានពេញអាង (ចំណុះ \(\displaystyle c\)) គេត្រូវប្រើពេលសរុប \(\displaystyle T\) ៖

\[T = \frac{c}{c\left(\frac{1}{t_1} + \frac{1}{t_2}\right)} = \frac{1}{\frac{t_1+t_2}{t_1 t_2}} = \frac{t_1 t_2}{t_1 + t_2} \text{ ម៉ោង}\]

បើ \(\displaystyle t_1 = 5\text{ ម៉ោង}\) និង \(\displaystyle t_2 = 20\text{ ម៉ោង}\) នោះបំពង់ទាំងពីរប្រើពេលរួមគ្នា ៖

\[T = \frac{5 \times 20}{5 + 20} = \frac{100}{25} = 4\text{ ម៉ោង}\]

  12. ចិន្តាមានសៀវភៅភាសាខ្មែរនិងភាសាអង់គ្លេសទាំងអស់ចំនួន 45 ក្បាល ។ \(\displaystyle \frac{4}{5}\) នៃសៀវភៅភាសាខ្មែរនិង \(\displaystyle \frac{3}{4}\) នៃសៀវភៅភាសាអង់គ្លេសជាសៀវភៅប្រលោមលោក ។ ដោយដឹងថាចិន្តាមានសៀវភៅប្រលោមលោកទាំងអស់ចំនួន 35 ក្បាល ។ តើចិន្តាមានសៀវភៅប្រលោមលោកជាភាសាខ្មែរប៉ុន្មានក្បាល ?

    1. ក.
