1. និយមន័យស្វ៊ីតនព្វន្ត

ឧទាហរណ៍ : ស្វ៊ីត \(\displaystyle 1, 2, 3, 4, 5, \dots\) មាន \(\displaystyle a_2 = a_1 + 1\), \(\displaystyle a_3 = a_2 + 1\), \(\displaystyle \dots\), \(\displaystyle a_{n+1} = a_n + 1\) ។ តួនីមួយៗ (ក្រៅពីតួទី 1) ស្មើតួមុនបូកចំនួនថេរ (\(\displaystyle 1\)) ហៅថា ផលសងរួម ។ ស្វ៊ីតនេះហៅថា ស្វ៊ីតនព្វន្ត ដែលមានផលសងរួម \(\displaystyle 1\) ។

និយមន័យ : ស្វ៊ីតនព្វន្តគឺជាស្វ៊ីតនៃចំនួនពិតដែលតួនីមួយៗ (ក្រៅពីតួទី 1) ស្មើនឹងតួមុនបូកចំនួនថេរ \(\displaystyle d\) ហៅថា ផលសងរួម ។

\[d = a_2 - a_1 = a_3 - a_2 = \dots = a_{n+1} - a_n\]

2. តួទី n នៃស្វ៊ីតនព្វន្ត

ឧទាហរណ៍ : ស្វ៊ីតនព្វន្ត \(\displaystyle 1, 2, 3, 4, 5, \dots\) មាន \(\displaystyle a_1 = 1\), \(\displaystyle d = 1\) ។ \(\displaystyle a_2 = a_1 + d\), \(\displaystyle a_3 = a_1 + 2d\), \(\displaystyle a_4 = a_1 + 3d\), \(\displaystyle a_5 = a_1 + 4d\) ។

ជាទូទៅ

: តួទី \(\displaystyle n\) នៃស្វ៊ីតនព្វន្តដែលមានតួទីមួយ \(\displaystyle a_1\) និងផលសងរួម \(\displaystyle d\) គឺ

\[a_n = a_1 + (n - 1)\times d\]
១លំហាត់គំរូ ១

ស្វ៊ីតនព្វន្ត \(\displaystyle 2, 8, 14, 20, \dots\) ។ ក. គណនាតួទី \(\displaystyle 20\) ខ. តើ \(\displaystyle 236\) ជាតួទីប៉ុន្មាន ?

ដំណោះស្រាយ

\(\displaystyle a_1 = 2\), \(\displaystyle d = 8 - 2 = 6\) ។ ក. \(\displaystyle a_{20} = 2 + 19\times6 = 116\) ។ ខ. \(\displaystyle 236 = 2 + 6(n - 1)\) ឬ \(\displaystyle 236 = 6n - 4\) ឱ្យ \(\displaystyle 6n = 240\) ហើយ \(\displaystyle n = 40\) : \(\displaystyle 236\) ជាតួទី \(\displaystyle 40\) ។

២លំហាត់គំរូ ២

ប្រាក់បៀវត្សក្នុងឆ្នាំទី \(\displaystyle 1\) គឺ \(\displaystyle 30\) លានរៀល និងឆ្នាំទី \(\displaystyle 7\) គឺ \(\displaystyle 60\) លានរៀល ។ សន្មតថាប្រាក់បៀវត្សប្រចាំឆ្នាំជាស្វ៊ីតនព្វន្ត ។ កំណត់ប្រាក់បៀវត្សក្នុងឆ្នាំទី \(\displaystyle 10\) ។

ដំណោះស្រាយ

\(\displaystyle a_7 = a_1 + 6d\) ឬ \(\displaystyle 60 = 30 + 6d\) ឱ្យ \(\displaystyle d = 5\) ។ \(\displaystyle a_{10} = a_7 + 3d = 60 + 15 = 75\) លានរៀល ។

✎ប្រតិបត្តិ

ក. ស្វ៊ីតនព្វន្តមួយមាន \(\displaystyle a_1 = 2\) និង \(\displaystyle a_2 = 9\) ។ កំណត់ \(\displaystyle a_5\) និងគណនា \(\displaystyle a_6\) ។ ខ. សៀវភៅមួយមាន \(\displaystyle 100\) ទំព័រ ចុះលេខ \(\displaystyle 1\) ដល់ \(\displaystyle 100\) ។ រកចំនួនទំព័រដែលលេខខាងចុងគឺ \(\displaystyle 5\) ។

មើលចម្លើយ

3. ផលបូក n តួដំបូងនៃស្វ៊ីតនព្វន្ត

ក្នុងស្វ៊ីតនព្វន្ត \(\displaystyle a_1, a_2, \dots, a_6\) ៖ \(\displaystyle a_1\) និង \(\displaystyle a_6\) ជា តួចុង ; \(\displaystyle a_2\) និង \(\displaystyle a_5\), \(\displaystyle a_3\) និង \(\displaystyle a_4\) ជា តួស្មើចម្ងាយពីតួចុង ។ \(\displaystyle a_1 + a_6 = 2a_1 + 5d\), \(\displaystyle a_2 + a_5 = 2a_1 + 5d\), \(\displaystyle a_3 + a_4 = 2a_1 + 5d\) ដូច្នេះ \(\displaystyle a_1 + a_6 = a_2 + a_5 = a_3 + a_4\) ។

ជាទូទៅ \(\displaystyle a_1 + a_n = a_2 + a_{n-1} = a_3 + a_{n-2} = \dots\) ។ យក \(\displaystyle S_n = a_1 + \dots + a_n\) និង \(\displaystyle S_n = a_n + \dots + a_1\) បូកគ្នា ៖ \(\displaystyle 2S_n = n(a_1 + a_n)\) ។

ជាទូទៅ

: ផលបូក \(\displaystyle n\) តួដំបូងនៃស្វ៊ីតនព្វន្ត

\[S_n = \frac n2(a_1 + a_n) = \frac{n\left[2a_1 + (n-1)d\right]}2\]
១លំហាត់គំរូ ១

ស្វ៊ីតនព្វន្ត \(\displaystyle 51, 47, 43, \dots\) ។ កំណត់ \(\displaystyle n\) ដែល \(\displaystyle S_n\) មានតម្លៃអតិបរមា ហើយរកតម្លៃនោះ ។

ដំណោះស្រាយ

\(\displaystyle d = -4\), \(\displaystyle a_n = 51 - 4(n-1) = 55 - 4n\) ។ \(\displaystyle a_n > 0\) ពេល \(\displaystyle n \le 13\) ហើយ \(\displaystyle a_n < 0\) ពេល \(\displaystyle n \ge 14\) ។ ដូច្នេះ \(\displaystyle S_n\) អតិបរមាត្រង់ \(\displaystyle n = 13\) : \(\displaystyle S_{13} = \dfrac{13(51 + 3)}2 = 351\) ។
