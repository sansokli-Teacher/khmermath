A. និយមន័យ

ចំណោទ 1 : តាមការសិក្សាស្រាវជ្រាវបានបង្ហាញឱ្យឃើញថាចំនួនប្រជាជននៅក្នុងសហគមន៍មួយកើនឡើងជារៀងរាល់ឆ្នាំដោយអត្រានៃ \(\displaystyle t(x) = 5 + 3x\) ដែល \(\displaystyle x\) ជាចំនួនឆ្នាំ ។ រកកំណើនប្រជាជននៅរយៈពេល \(\displaystyle 8\) ឆ្នាំទៅមុខទៀត ។

តាង \(\displaystyle T(x)\) ជាកំណើនប្រជាជន គេបាន \(\displaystyle T(x)\) ជាអាំងតេក្រាលនៃ \(\displaystyle t(x)\) គេបាន \(\displaystyle T(x) = \int t(x)dx = \int (5 + 3x)dx = \int 5dx + 3\int xdx = 5x + \frac{3}{2}x^{2} + c\) ។ ប្រជាជនក្នុងពេលបច្ចុប្បន្ន \(\displaystyle T(0) = 5 \times 0 + \frac{3}{2} \times 0^{2} + c = c\) ។ កំណើនប្រជាជនរយៈពេល \(\displaystyle 8\) ឆ្នាំ \(\displaystyle T(8) = 5 \times 8 + \frac{3}{2} \times 8^{2} + c = 40 + 96 + c = 136 + c\) ដូច្នេះ កំណើនប្រជាជនរយៈពេល \(\displaystyle 8\) ឆ្នាំទៅមុខទៀត \(\displaystyle T(8) - T(0) = 136 + c - c = 136\) នាក់ ផលដកនេះ ហៅថាអាំងតេក្រាលកំណត់ពី \(\displaystyle 0\) ទៅ \(\displaystyle 8\) នៃ \(\displaystyle t(x)\) ។

ចំណោទ 2 : វត្ថុមួយផ្លាស់ទីតាមទិសដេកដោយល្បឿន \(\displaystyle V(t) = 5 + 3t^{2}\text{ m/mn}\) ។ រកកំណើនចម្ងាយនៃវត្ថុដែលត្រូវនឹងកំណើនពេលពីខណៈ \(\displaystyle t = 3\text{ mn}\) ទៅដល់ខណៈ \(\displaystyle t = 5\text{ mn}\) ។

តាង \(\displaystyle S(t)\) ជាចម្ងាយចរ នោះគេបាន \(\displaystyle S'(t) = V(t)\) ដូច្នេះ \(\displaystyle S(t) = \int V(t)dt = \int (5 + 3t^{2})dt = 5t + t^{3} + c\) ចម្ងាយចរនៃវត្ថុនៅខណៈ \(\displaystyle t = 3\text{ mn}\) គឺ \(\displaystyle S(3) = 5 \times 3 + 3^{3} + c = 42 + c\) ចម្ងាយចរនៃវត្ថុនៅខណៈ \(\displaystyle t = 5\text{ mn}\) គឺ \(\displaystyle S(5) = 5 \times 5 + 5^{3} + c = 150 + c\) ដូច្នេះ កំណើនចម្ងាយចរនៃវត្ថុនៅចន្លោះខណៈ \(\displaystyle t = 3\text{ mn}\) និង \(\displaystyle t = 5\text{ mn}\) \(\displaystyle S(5) - S(3) = 150 + c - 42 - c = 108\text{ m}\) ។ ផលដកនេះហៅថា អាំងតេក្រាលកំណត់ពី \(\displaystyle 3\) ទៅ \(\displaystyle 5\) នៃ \(\displaystyle V(t)\) ។

    ដូច្នេះ \(\displaystyle \int_{0}^{4} 3e^{x}dx = \int_{0}^{2} 3e^{x}dx + \int_{2}^{4} 3e^{x}dx\) ។

  3. គ.

    បើអនុគមន៍ \(\displaystyle f\) កំណត់ និងជាប់លើចន្លោះ \(\displaystyle [a, c]\) និង \(\displaystyle a < b < c\) នោះ \(\displaystyle \int_{a}^{b} f(x)dx + \int_{b}^{c} f(x)dx = \int_{a}^{c} f(x)dx\) ។
    សម្រាយបញ្ជាក់ :

    \[\int_{a}^{b} f(x)dx + \int_{b}^{c} f(x)dx = F(b) - F(a) + F(c) - F(b) = F(c) - F(a) = \int_{a}^{c} f(x)dx\]

    នាំឱ្យ \(\displaystyle \int_{a}^{b} f(x)dx + \int_{b}^{c} f(x)dx = \int_{a}^{c} f(x)dx\) ។

    ឧទាហរណ៍ : បង្ហាញថា \(\displaystyle \int_{0}^{\frac{\pi}{3}} 3\sin xdx = 3\int_{0}^{\frac{\pi}{3}} \sin xdx\)
    \(\displaystyle \int_{0}^{\frac{\pi}{3}} 3\sin xdx = [-3\cos x]_{0}^{\frac{\pi}{3}} = -3\cos\frac{\pi}{3} + 3\cos 0 = \frac{-3}{2} + 3 = \frac{3}{2}\)
    \(\displaystyle 3\int_{0}^{\frac{\pi}{3}} \sin xdx = 3[-\cos x]_{0}^{\frac{\pi}{3}} = 3\left(-\cos\frac{\pi}{3} + \cos 0\right) = -\frac{3}{2} + 3 = \frac{3}{2}\)
    ដូច្នេះ \(\displaystyle \int_{0}^{\frac{\pi}{3}} 3\sin xdx = 3\int_{0}^{\frac{\pi}{3}} \sin xdx\) ។

  4. ឃ. \(\displaystyle \int_{a}^{b} kf(x)dx = k\int_{a}^{b} f(x)dx\) ដែល \(\displaystyle k \in \mathbb{R}\) ។
    សម្រាយបញ្ជាក់ : \(\displaystyle k\int_{a}^{b} f(x)dx = k[F(b) - F(a)] = kF(b) - kF(a) = \int_{a}^{b} kf(x)dx\) ។
  5. ង.

    បើ \(\displaystyle \int_{a}^{b} f(x)dx\) និង \(\displaystyle \int_{a}^{b} g(x)dx\) មានន័យ នោះ \(\displaystyle \int_{a}^{b} [f(x) \pm g(x)]dx = \int_{a}^{b} f(x)dx \pm \int_{a}^{b} g(x)dx\) ។
    សម្រាយបញ្ជាក់ :

    \[\begin{aligned} \int_{a}^{b} [f(x) - g(x)]dx &= F(b) - G(b) - F(a) + G(a) \quad (F, G \text{ ជាព្រីមីទីវរៀងគ្នានៃ } f, g) \\ &= [F(b) - F(a)] - [G(b) - G(a)] \\ &= \int_{a}^{b} f(x)dx - \int_{a}^{b} g(x)dx \text{ ។} \end{aligned}\]
    \[\begin{aligned} \int_{a}^{b} [f(x) + g(x)]dx &= F(b) + G(b) - F(a) - G(a) \quad (F, G \text{ ជាព្រីមីទីវរៀងគ្នានៃ } f, g) \\ &= [F(b) - F(a)] + [G(b) - G(a)] \\ &= \int_{a}^{b} f(x)dx + \int_{a}^{b} g(x)dx \text{ ។} \end{aligned}\]

    ឧទាហរណ៍ : គណនា \(\displaystyle \int_{2}^{4} (4x - 5)dx + \int_{2}^{4} (5 - 6x)dx\)

    \[\begin{aligned} \int_{2}^{4} (4x - 5)dx + \int_{2}^{4} (5 - 6x)dx &= \int_{2}^{4} [(4x - 5) + (5 - 6x)]dx \\ &= \int_{2}^{4} -2xdx = [-x^{2}]_{2}^{4} = -16 + 4 = -12 \end{aligned}\]

    ដូច្នេះ \(\displaystyle \int_{2}^{4} (4x - 5)dx + \int_{2}^{4} (5 - 6x)dx = -12\) ។

  6. ច.

    បើ \(\displaystyle \int_{a}^{b} [\alpha f(x) + \beta g(x)]dx = \alpha \int_{a}^{b} f(x)dx + \beta \int_{a}^{b} g(x)dx\) ។

    ឧទាហរណ៍ : គណនា \(\displaystyle \int_{2}^{4} \left[\frac{3}{x^{2}} + \frac{1}{2}x\right]dx\)

    \[\begin{aligned} \int_{2}^{4} \left[\frac{3}{x^{2}} + \frac{1}{2}x\right]dx &= \int_{2}^{4} \frac{3}{x^{2}}dx + \int_{2}^{4} \frac{1}{2}xdx = 3\int_{2}^{4} \frac{1}{x^{2}}dx + \frac{1}{2}\int_{2}^{4} xdx \\ &= \left[-\frac{3}{x}\right]_{2}^{4} + \left[\frac{1}{4}x^{2}\right]_{2}^{4} = \frac{-3}{4} + \frac{3}{2} + \frac{1}{4}4^{2} - \frac{1}{4}2^{2} = \frac{-3 + 6}{4} + 3 = \frac{15}{4} \text{ ។} \end{aligned}\]

C. គណនាអាំងតេក្រាលកំណត់ដោយប្តូរអថេរ

បើ \(\displaystyle u = g(x)\) ជាប់ និងមានដេរីវេលើ \(\displaystyle [a, b]\) នោះ \(\displaystyle \int_{a}^{b} f[g(x)]g'(x)dx = \int_{g(a)}^{g(b)} f(u)du\) ។

សម្រាយបញ្ជាក់ : តាង \(\displaystyle F\) ជាព្រីមីទីវនៃ \(\displaystyle f\) នោះ \(\displaystyle F' = f\) និង

\[\int_{a}^{b} f[g(x)]g'(x)dx = \int_{a}^{b} F'(g(x))g'(x)dx = \Big[F[g(x)]\Big]_{a}^{b} = F[g(b)] - F[g(a)] = \int_{g(a)}^{g(b)} f(u)du \text{ ។}\]
•លំហាត់គំរូ

    បើ \(\displaystyle x = 0\) នោះ \(\displaystyle u = 1\)
    បើ \(\displaystyle x = 2\) នោះ \(\displaystyle u = 5\)
    គេបាន \(\displaystyle \int_{0}^{2} x(x^{2} + 1)^{3}dx = \int_{1}^{5} u^{3}\frac{1}{2}du = \frac{1}{2}\int_{1}^{5} u^{3}du = \left[\frac{u^{4}}{8}\right]_{1}^{5} = \frac{625}{8} - \frac{1}{8} = 78\)
    នាំឱ្យ \(\displaystyle \int_{0}^{2} x(x^{2} + 1)^{3}dx = 78\) ។
  2. ខ. គណនា \(\displaystyle \int_{1}^{2} \frac{3x^{2}}{(x^{3} + 1)^{2}}dx\)

D. រូបមន្តអាំងតេក្រាលដោយផ្នែក

បើ \(\displaystyle f\) និង \(\displaystyle g\) ជាអនុគមន៍ជាប់លើចន្លោះ \(\displaystyle [a, b]\) និងមានដេរីវេលើចន្លោះ \(\displaystyle (a, b)\) នោះ \(\displaystyle \int_{a}^{b} f(x) \cdot g'(x)dx = [f(x) \cdot g(x)]_{a}^{b} - \int_{a}^{b} g(x) \cdot f'(x)dx\) ។

សម្រាយបញ្ជាក់ : គេបាន \(\displaystyle (f(x) \cdot g(x))' = f'(x) \cdot g(x) + f(x) \cdot g'(x)\)

\[\int_{a}^{b} (f(x) \cdot g(x))'dx = \int_{a}^{b} f(x) \cdot g'(x)dx + \int_{a}^{b} g(x) \cdot f'(x)dx\]
\[\int_{a}^{b} f(x) \cdot g'(x)dx + \int_{a}^{b} g(x) \cdot f'(x)dx = [f(x) \cdot g(x)]_{a}^{b}\]
\[\int_{a}^{b} f(x) \cdot g'(x)dx = [f(x) \cdot g(x)]_{a}^{b} - \int_{a}^{b} g(x) \cdot f'(x)dx \text{ ។}\]
•លំហាត់គំរូ

គណនា \(\displaystyle A = \int_{0}^{\frac{\pi}{2}} x\cos xdx\), \(\displaystyle B = \int_{0}^{1} xe^{x}dx\) ។

ដំណោះស្រាយ

  • គណនា \(\displaystyle A = \int_{0}^{\frac{\pi}{2}} x\cos xdx\)
    តាង \(\displaystyle f(x) = x\), \(\displaystyle f'(x) = 1\)
    \(\displaystyle g(x) = \sin x\), \(\displaystyle g'(x) = \cos x\)

    \[\begin{aligned} A &= \int_{0}^{\frac{\pi}{2}} x\cos xdx = [x\sin x]_{0}^{\frac{\pi}{2}} - \int_{0}^{\frac{\pi}{2}} \sin xdx \\ &= \frac{\pi}{2}\sin\frac{\pi}{2} - 0 + [\cos x]_{0}^{\frac{\pi}{2}} = \frac{\pi}{2} + 0 - 1 = \frac{\pi}{2} - 1 \end{aligned}\]

    ដូច្នេះ \(\displaystyle A = \int_{0}^{\frac{\pi}{2}} x\cos xdx = \frac{\pi}{2} - 1\) ។

  • គណនា \(\displaystyle B = \int_{0}^{1} xe^{x}dx\)
    តាង \(\displaystyle f(x) = x\), \(\displaystyle f'(x) = 1\)
    \(\displaystyle g(x) = e^{x}\), \(\displaystyle g'(x) = e^{x}\)

    \[B = \int_{0}^{1} xe^{x}dx = [xe^{x}]_{0}^{1} - \int_{0}^{1} e^{x}dx = e - 0 - [e^{x}]_{0}^{1} = e - e + 1 = 1\]

    ដូច្នេះ \(\displaystyle B = \int_{0}^{1} xe^{x}dx = 1\) ។

E. ការអនុវត្តលើអាំងតេក្រាល

•លំហាត់គំរូ

ក្រុមហ៊ុនលក់រថយន្តមួយទទួលប្រាក់ចំណេញតាមបម្រែបម្រួលនៃរថយន្តដែលបានលក់ ។ អត្រាប្រាក់ចំណេញបន្ថែមកំណត់ដោយអនុគមន៍ \(\displaystyle P(x) = 30 - 0.28x\) ដែល \(\displaystyle x\) ជាចំនួនរថយន្តនិង \(\displaystyle P(x)\) គិតជាសែនរៀល ។ រកបម្រែបម្រួលនៃប្រាក់ចំណេញពីការលក់រថយន្តចាប់ពីចំនួន \(\displaystyle 10\) ទៅ \(\displaystyle 30\) គ្រឿង ។

ដំណោះស្រាយ

បម្រែបម្រួលនៃប្រាក់ចំណេញពីការលក់រថយន្តចាប់ពីចំនួន \(\displaystyle 10\) ទៅ \(\displaystyle 30\) គ្រឿង អាចគណនាតាមអាំងតេក្រាលកំណត់នៃអនុគមន៍ប្រាក់ចំណេញបន្ថែម \(\displaystyle P(x) = 30 - 0.28x\) ពី \(\displaystyle 10\) ទៅ \(\displaystyle 30\) គេបាន
